一

集合与常用逻辑用语

Sets & Logic

基础知识 · Core knowledge

集合的三性与表示
确定性 · 互异性 · 无序性（互异性最常设陷阱：求出参数后必须回代检验元素不重复）。 常用数集：N 自然数、N* 正整数、Z 整数、Q 有理数、R 实数。
关系与子集个数
∈ / ∉、⊆ / ⊊、=。∅ 是任何集合的子集，是任何非空集合的真子集。 含 n 个元素的集合有 2n 个子集、2n−1 个真子集、2n−1 个非空子集、2n−2 个非空真子集。
三种运算 + 德摩根律
交 A∩B、并 A∪B、补 ∁UA。 德摩根律：∁U(A∩B) = (∁UA)∪(∁UB)，∁U(A∪B) = (∁UA)∩(∁UB)。 处理数集时务必画数轴，注意端点开闭。
充分条件与必要条件
若 p ⇒ q，则 p 是 q 的充分条件、q 是 p 的必要条件。 集合观点：记 p、q 对应集合 A、B，则 A⊆B ⇔ p 是 q 的充分条件；A⊊B ⇔ 充分不必要。“小范围 ⇒ 大范围”。
全称量词与存在量词的否定
“∀x∈M, p(x)” 的否定是 “∃x∈M, ¬p(x)”；反之 ∃ 的否定为 ∀。改量词、否结论。 全称命题常转化为最值（恒成立），存在命题常转化为能取到。
易 · Easy 集合的交并运算 考点：数轴 + 端点开闭

题已知集合 A = {x | −1 < x < 3}，B = {x | x2 ≤ 4}。求 A∩B 与 A∪B。

解
  1. 先解 B：x2 ≤ 4 ⇔ −2 ≤ x ≤ 2，即 B = [−2, 2]。
  2. 而 A = (−1, 3)。在数轴上画出两段。
  3. 取公共部分（交）：左端取较大者 −1（开），右端取较小者 2（闭）⇒ A∩B = (−1, 2]。
  4. 取合并部分（并）：左端 −2（闭），右端 3（开）⇒ A∪B = [−2, 3)。
答：A∩B = (−1, 2]，A∪B = [−2, 3)。
点拨：数集运算一律画数轴。端点开闭跟随原不等式：x2≤4 含等号 ⇒ 闭；−1<x 不含 ⇒ 开。交并端点的开闭由“取到该点的那个集合”决定。
中 · Medium 含参子集问题 考点：分类讨论 + 空集 / 互异性

题已知 A = {x | x2 − 3x + 2 = 0}，B = {x | x2 − (a+1)x + a = 0}。若 B ⊆ A，求实数 a 的所有取值。

解
  1. 先求 A：x2−3x+2 = (x−1)(x−2) = 0 ⇒ A = {1, 2}。
  2. B 的方程因式分解：x2−(a+1)x+a = (x−1)(x−a) = 0 ⇒ 根为 x = 1 与 x = a。
  3. 讨论：若 a = 1，两根相同，B = {1} ⊆ A ✔。
  4. 若 a ≠ 1，B = {1, a}。要 B ⊆ A = {1,2}，需 a ∈ {2}（a 不能取 1 已排除）⇒ a = 2，此时 B = {1,2} ✔。
答：a = 1 或 a = 2。
点拨：“B⊆A”类问题必须考虑 B 退化的情形——本题是重根 a=1 使 B 变独点集；若 B 由不等式给出，还要单独讨论 B=∅。漏掉退化情形是最常见丢分点。
难 · Difficult 量词 + 复合命题求参数范围 考点：恒成立→最值、存在→判别式、p∧q

题已知命题 p：∀x∈[1, 2]，x2 − a ≥ 0；命题 q：∃x∈R，x2 + 2ax + 2 − a = 0。若 p ∧ q 为真，求 a 的取值范围。

解
  1. 解 p（全称→最小值）：∀x∈[1,2] 有 a ≤ x2，等价于 a ≤ (x2)min。x2 在 [1,2] 上最小值为 12 = 1 ⇒ p 真 ⇔ a ≤ 1。
  2. 解 q（存在实根→判别式）：关于 x 的方程有实根 ⇔ Δ ≥ 0：(2a)2 − 4(2 − a) ≥ 0 ⇒ 4a2 + 4a − 8 ≥ 0 ⇒ a2 + a − 2 ≥ 0 ⇒ (a+2)(a−1) ≥ 0 ⇒ q 真 ⇔ a ≤ −2 或 a ≥ 1。
  3. p∧q 为真 ⇒ 两者同时成立，取交集：{a ≤ 1} ∩ {a ≤ −2 或 a ≥ 1}。
  4. 分支一：a ≤ 1 且 a ≤ −2 ⇒ a ≤ −2。分支二：a ≤ 1 且 a ≥ 1 ⇒ a = 1。合并。
答：a ≤ −2 或 a = 1，即 a ∈ (−∞, −2] ∪ {1}。
点拨：两条黄金转化——全称恒成立 a≤f(x) 恒成立 ⇔ a≤f(x)min；存在成立 ⇔ 与最值反向或用判别式。最后 p∧q 取交集、p∨q 取并集。别忘了孤立点 a=1 也是解，它恰好是两区间的“接触点”，极易漏写。
二

函数与基本初等函数

Functions

基础知识 · Core knowledge

三要素与定义域优先
定义域、对应关系、值域。一切函数问题先看定义域：根号内 ≥0、分母 ≠0、对数真数 >0。求解析式常用待定系数、换元、配凑。
四大性质
单调性（定义法或 f′ 符号）、奇偶性（定义域须关于原点对称，再看 f(−x) = ±f(x)）、周期性（f(x+T)=f(x)）、对称性（轴对称 f(a+x)=f(a−x)）。偶函数 ⇔ 图象关于 y 轴对称 ⇔ f(x)=f(|x|)。
基本初等函数
指数 y=ax、对数 y=logax（互为反函数）、幂函数。比较大小：找中间量 0 或 1，或借助函数单调性。
零点与图象变换
零点存在定理：f 连续且 f(a)·f(b)<0 ⇒ (a,b) 内有零点。零点个数常转化为两图象交点个数。图象变换：平移、伸缩、翻折（|·|）。
易 · Easy定义域考点：多约束取交集

题求函数 f(x) = lg(2 − x) + √(x + 1) 的定义域。

解
  1. 对数真数 > 0：2 − x > 0 ⇒ x < 2。
  2. 根号内 ≥ 0：x + 1 ≥ 0 ⇒ x ≥ −1。
  3. 两约束取交集：−1 ≤ x < 2。
答：定义域为 [−1, 2)。
点拨：定义域是若干条件的交集，逐条列不等式再取公共部分；根号取闭、真数/分母取开，端点开闭别混。
中 · Medium偶函数 + 单调性解不等式考点：偶函数化 |x|

题已知 f(x) 是定义在 R 上的偶函数，且在 [0, +∞) 上单调递增。解不等式 f(2x − 1) < f(3)。

解
  1. 偶函数在 [0,∞) 递增 ⇒ f 的大小只由自变量绝对值决定：f(u) = f(|u|)，且 |u| 越大 f 越大。
  2. 故 f(2x−1) < f(3) ⇔ |2x − 1| < 3。
  3. 解：−3 < 2x − 1 < 3 ⇒ −2 < 2x < 4 ⇒ −1 < x < 2。
答：解集为 (−1, 2)。
点拨：见“偶函数 + 单调”立刻把两边都套上绝对值：f(A)<f(B) ⇔ |A|<|B|（在递增侧）。这是把抽象函数不等式转成普通不等式的关键一步。
难 · Difficult奇函数 + 抽象周期考点：函数方程→周期与对称

题设 f(x) 是 R 上的奇函数，满足 f(x + 2) = −f(x)，当 0 ≤ x ≤ 1 时 f(x) = x。
(1) 求证 f 是周期函数并求周期；(2) 求 f 在 [1, 2] 上的解析式；(3) 求 f(2025.5)。

解
  1. (1) 由 f(x+2)=−f(x) 得 f(x+4)=−f(x+2)=f(x) ⇒ 周期 T = 4。
  2. (2) 又 f 为奇：f(x+2)=−f(x)=f(−x)，即图象关于 x=1 对称：f(1+t)=f(1−t)。设 x∈[1,2]，令 t=x−1∈[0,1]，则 f(x)=f(1+t)=f(1−t)=1−t=2−x。
  3. (3) 用周期 4：2025.5 = 4×506 + 1.5，故 f(2025.5)=f(1.5)。由 (2)，f(1.5)=2−1.5=0.5。
答：(1) 周期 4；(2) f(x)=2−x，x∈[1,2]；(3) f(2025.5)=0.5。
点拨：“f(x+2)=−f(x)”这类关系先迭代求周期（再套一次得 +4 还原）。奇偶性 + 平移关系常隐藏对称轴；求大自变量的值就用周期把它约化到已知区间。
三

导数及其应用

Derivatives

基础知识 · Core knowledge

几何意义与切线
f′(x0) = 曲线在 x0 处切线斜率。切线方程 y − f(x0) = f′(x0)(x − x0)。“过某点”的切线要设切点，不一定在曲线上。
求导公式与法则
(xn)′=nxn−1，(ex)′=ex，(lnx)′=1x，(sinx)′=cosx。积 (uv)′=u′v+uv′；商 (uv)′=u′v−uv′v2；复合逐层相乘。
单调性 · 极值 · 最值
f′>0 增、f′<0 减；f′变号处取极值。闭区间最值 = 比较极值与端点值。含参先求 f′ 的零点并按零点位置分类讨论。
证明不等式 / 恒成立
常法：分离参数 a≥g(x) 恒成立 ⇔ a≥g(x)max；或构造函数求最小值 ≥0。常用放缩 ex ≥ x+1、lnx ≤ x−1。
易 · Easy求切线方程考点：f′(x₀) 即斜率

题求曲线 f(x) = x3 − 2x 在点 x = 1 处的切线方程。

解
  1. 切点纵坐标：f(1) = 1 − 2 = −1，切点 (1, −1)。
  2. 求导：f′(x) = 3x2 − 2，斜率 f′(1) = 3 − 2 = 1。
  3. 点斜式：y − (−1) = 1·(x − 1) ⇒ y = x − 2。
答：切线方程为 y = x − 2。
点拨：“在 x0 处”三步走：求 f(x0) 定切点、求 f′(x0) 定斜率、点斜式。若题目说“过点 P”，P 未必是切点，需另设切点 (t, f(t)) 列方程。
中 · Medium单调区间、极值与闭区间最值考点：f′ 列表判号

题已知 f(x) = x3 − 3x2 + 2。求其单调区间与极值，并求在 [−1, 3] 上的最大、最小值。

解
  1. f′(x) = 3x2 − 6x = 3x(x − 2)，零点 x = 0, 2。
  2. 判号：x<0 或 x>2 时 f′>0（增）；0<x<2 时 f′<0（减）。
  3. 极大值 f(0) = 2；极小值 f(2) = 8 − 12 + 2 = −2。
  4. 端点：f(−1) = −1 − 3 + 2 = −2，f(3) = 27 − 27 + 2 = 2。
  5. 比较 {f(−1), f(0), f(2), f(3)} = {−2, 2, −2, 2}。
答：增区间 (−∞,0)、(2,+∞)，减区间 (0,2)；极大 2、极小 −2；[−1,3] 上最大值 2、最小值 −2。
点拨：闭区间最值只可能在极值点或端点取得，把这几个候选值全算出来比较即可，不要漏端点。列 f′ 符号表能避免判号出错。
难 · Difficult含参讨论 + 导数证不等式考点：分类讨论、最小值≥0

题已知 f(x) = ex − ax − 1（a ∈ R）。
(1) 讨论 f(x) 的单调性；(2) 当 a = 1 时，证明 f(x) ≥ 0。

解
  1. (1) f′(x) = ex − a。
  2. 若 a ≤ 0：ex > 0 ≥ a，f′>0 恒成立，f 在 R 上单调递增。
  3. 若 a > 0：f′=0 ⇒ x=lna。x<lna 时 f′<0（减），x>lna 时 f′>0（增）。
  4. (2) a=1：f(x)=ex−x−1，f′(x)=ex−1。由 (1) 知 x=ln1=0 为唯一极小值点。
  5. 最小值 f(0)=e0−0−1=0，故对一切 x，f(x) ≥ f(0)=0，即 ex ≥ x+1。
答：(1) a≤0 时 R 上递增；a>0 时 (−∞,lna) 减、(lna,+∞) 增。(2) 得证。
点拨：含参单调性的分界就是 f′ 能否变号——a≤0 时 ex−a 恒正故不讨论。证不等式 f≥0 的通法：求 f 的最小值并证其 ≥0。ex≥x+1 与 lnx≤x−1 是压轴放缩的两把钥匙。
四

三角函数与解三角形

Trigonometry

基础知识 · Core knowledge

同角关系与诱导公式
sin2α+cos2α=1，tanα=sinαcosα。诱导公式口诀“奇变偶不变，符号看象限”。
和差角、二倍角、辅助角
sin2α=2sinαcosα，cos2α=2cos2α−1=1−2sin2α。辅助角：asinx+bcosx=√(a2+b2) sin(x+φ)。
y = A sin(ωx + φ)
周期 T = 2πω；单调、对称轴由整体 ωx+φ 代入正弦的相应区间求解；图象平移“左加右减”。
解三角形
正弦定理 asinA=2R；余弦定理 a2=b2+c2−2bccosA；面积 S=½absinC。投影公式 a=bcosC+ccosB。
易 · Easy同角关系求值考点：象限定号 + 二倍角

题已知 sinα = 35，α ∈ (π2, π)。求 cosα、tanα 与 sin2α。

解
  1. α 在第二象限，cosα < 0：cosα = −√(1 − sin2α) = −√(1 − 925) = −45。
  2. tanα = sinαcosα = 3/5−4/5 = −34。
  3. sin2α = 2sinαcosα = 2·35·(−45) = −2425。
答：cosα = −4/5，tanα = −3/4，sin2α = −24/25。
点拨：用 sin2+cos2=1 开方时，符号由象限决定——这是最易错处。第二象限 sin>0、cos<0、tan<0。
中 · Medium化一个角 + 周期与单调考点：降幂 + 辅助角

题已知 f(x) = sin2x + √3 sinx cosx。求 f(x) 的最小正周期与单调递增区间。

解
  1. 降幂：sin2x = 1−cos2x2；倍角：√3 sinxcosx = √32 sin2x。
  2. f(x) = 12 + (√32 sin2x − 12 cos2x) = 12 + sin(2x − π6)。
  3. 周期 T = 2π2 = π。
  4. 递增：−π2+2kπ ≤ 2x−π6 ≤ π2+2kπ ⇒ −π6+kπ ≤ x ≤ π3+kπ。
答：最小正周期 π；单调递增区间 [−π6+kπ, π3+kπ]（k∈Z）。
点拨：三角化简目标永远是“化成一个 A sin(ωx+φ)+B”：先降幂去平方、再用辅助角合并。求单调区间时把 (ωx+φ) 看成整体代入 sin 的增区间 [−π/2+2kπ, π/2+2kπ]。
难 · Difficult解三角形 + 周长范围考点：投影公式、边化角求范围

题在 △ABC 中，角 A,B,C 的对边为 a,b,c，且 (2a − c)cosB = bcosC。
(1) 求 B；(2) 若 b = √3，求 △ABC 周长的取值范围。

解
  1. (1) 展开：2acosB = ccosB + bcosC。由投影公式 ccosB+bcosC = a，故 2acosB = a ⇒ cosB = 12 ⇒ B = π3。
  2. (2) 由正弦定理 bsinB = √3√3/2 = 2，故 a = 2sinA，c = 2sinC，且 A+C = 2π3。
  3. a+c = 2[sinA + sin(2π3−A)] = 2[32sinA + √32cosA] = 2√3 sin(A + π6)。
  4. A ∈ (0, 2π3) ⇒ A+π6 ∈ (π6, 5π6) ⇒ sin(A+π6) ∈ (12, 1]。
  5. 故 a+c ∈ (√3, 2√3]，周长 = a+c+√3 ∈ (2√3, 3√3]。
答：(1) B = π/3；(2) 周长范围 (2√3, 3√3]（等边时取最大 3√3）。
点拨：“边·cos + 边·cos”形式优先想投影公式或正弦定理边化角。求周长/面积范围：把目标用一个角表示，化成 R sin(A+φ)，再由 A 的定义域推 sin 的范围。注意 A 的开区间导致范围左开右闭。

平面向量与复数

Vectors & Complex Numbers

基础知识 · Core knowledge

坐标运算
设 a=(x1,y1)，b=(x2,y2)。a·b=x1x2+y1y2，|a|=√(x12+y12)。
平行、垂直、夹角
a∥b ⇔ x1y2−x2y1=0；a⊥b ⇔ a·b=0；cosθ=a·b|a||b|。模长平方：|a±b|2=|a|2±2a·b+|b|2。
复数
z=a+bi，共轭 z=a−bi，|z|=√(a2+b2)，i2=−1。除法：分子分母同乘分母的共轭以实数化。
易 · Easy复数除法考点：分母实数化

题计算 1+2i1−i，并写出其虚部。

解
  1. 分子分母同乘 (1+i)：(1+2i)(1+i)(1−i)(1+i)。
  2. 分母 (1−i)(1+i) = 1 − i2 = 2。分子 = 1 + i + 2i + 2i2 = 1 + 3i − 2 = −1 + 3i。
  3. 故原式 = −1+3i2 = −12 + 32 i。
答：原式 = −½ + (3/2)i，虚部为 3/2。
点拨：复数除法固定套路——分母乘共轭把分母变实数。注意“虚部”指系数 3/2，不含 i；别把 (3/2)i 当虚部。
中 · Medium平行条件与夹角考点：坐标法

题已知向量 a = (1, 2)，b = (−2, k)。(1) 若 a ∥ b，求 k；(2) 若 k = 3，求 a 与 b 夹角的余弦值。

解
  1. (1) a∥b ⇔ 1·k − 2·(−2) = 0 ⇒ k + 4 = 0 ⇒ k = −4。
  2. (2) k=3 时 b=(−2,3)。a·b = 1·(−2)+2·3 = 4。
  3. |a| = √5，|b| = √13。cosθ = 4√5·√13 = 4√65 = 4√6565。
答：(1) k = −4；(2) cosθ = 4√65 / 65。
点拨：平行用叉乘式 x1y2−x2y1=0（不要写成对应成比例再讨论分母为零）；垂直用点乘=0。夹角余弦最后记得分母有理化。
难 · Difficult含参模长最值考点：|c|²展开成 t 的二次

题已知 |a| = 2，|b| = 1，a 与 b 的夹角为 60°。设 c = a + tb（t ∈ R），求 |c| 的最小值。

解
  1. 先求数量积：a·b = |a||b|cos60° = 2·1·12 = 1。
  2. |c|2 = |a + tb|2 = |a|2 + 2t(a·b) + t2|b|2 = 4 + 2t + t2。
  3. 关于 t 的二次函数 t2+2t+4 = (t+1)2+3，在 t = −1 处取最小值 3。
  4. 故 |c|min = √3。
答：|c| 的最小值为 √3（当 t = −1 时取得）。
点拨：向量模的最值，先平方转成数量积再化为参数的二次函数配方。核心一步是把 |·|2 展开——凡遇“求模/证垂直/求夹角”，几乎都靠 |a±b|2 这条恒等式。

数列

Sequences & Series

基础知识 · Core knowledge

两种基本数列

易 · Easy等差基本量考点：求 d, a₁, Sₙ

题等差数列 {an} 中，a2 = 3，a5 = 9。求通项 an 与前 10 项和 S10。

解
  1. d = a5−a25−2 = 9−33 = 2，a1 = a2 − d = 1。
  2. an = 1 + (n−1)·2 = 2n − 1。
  3. S10 = 10(a1+a10)2 = 5·(1 + 19) = 100。
答：an = 2n − 1，S10 = 100。
点拨：等差“知二求一”：任意两项差 = 项数差 × d。求和优先用 Sn=n×(首+末)/2，比代 na1+... 更省。
中 · Medium裂项相消求和考点：拆成差的形式

题已知 an = 2n − 1。求数列 { 1anan+1 } 的前 n 项和 Tn。

解
  1. 通项 = 1(2n−1)(2n+1) = 12(12n−1 − 12n+1)。
  2. 累加相消：Tn = 12[(1−13) + (13−15) + … + (12n−1−12n+1)]。
  3. 中间项全抵消，剩首尾：Tn = 12(1 − 12n+1) = n2n+1。
答：Tn = n / (2n + 1)。
点拨：分母是两个等差项相乘时想裂项：1anan+1=1d(1an−1an+1)。别忘前面的系数 1/d（这里 d=2）。
难 · Difficult构造等比 + 错位相减考点：aₙ₊₁=paₙ+q、n·2ⁿ 求和

题数列 {an} 满足 a1 = 1，an+1 = 2an + 1。
(1) 证明 {an + 1} 为等比数列并求 an；(2) 求 Tn = Σk=1n k·ak。

解
  1. (1) 两边加 1：an+1+1 = 2an+2 = 2(an+1)。又 a1+1 = 2，故 {an+1} 是首项 2、公比 2 的等比数列 ⇒ an+1 = 2n，即 an = 2n − 1。
  2. (2) kak = k(2k−1) = k·2k − k，分组：Tn = P − Σk，其中 P = Σk=1n k·2k。
  3. 错位相减求 P： P = 1·2 + 2·22 + … + n·2n；2P = 1·22 + … + n·2n+1。相减：−P = (2+22+…+2n) − n·2n+1 = (2n+1−2) − n·2n+1。
  4. 故 P = (n−1)·2n+1 + 2。而 Σk = n(n+1)2。
  5. Tn = (n−1)·2n+1 + 2 − n(n+1)2。（验 n=1：0+2−1 = 1 = 1·a1 ✔）
答：(1) an = 2n − 1；(2) Tn = (n−1)·2n+1 + 2 − n(n+1)2。
点拨：“an+1=pan+q”型加常数 qp−1 配成等比（此处加 1）。求 Σk·qk 一律错位相减：乘公比、错位、相减，中间成等比数列。最后代 n=1 验算是自查利器。

Inequalities

一元二次不等式
先化 >0 标准形、求根、看开口。a>0 时 “大于取两边、小于取中间”。
基本（均值）不等式
a,b > 0 时 a+b ≥ 2√(ab)，等号 ⇔ a=b。使用口诀“一正、二定、三相等”：各项为正、和或积为定值、能取等。
两大技巧
配凑（凑出定值乘积）与 “1”的代换（把已知的“= 1”乘进目标式再展开用均值）。注：线性规划已退出新高考。
易 · Easy一元二次不等式考点：因式分解定解集

题解不等式 x2 − x − 6 ≤ 0。

解
  1. 因式分解：x2 − x − 6 = (x − 3)(x + 2)。
  2. 开口向上、取 ≤0（中间部分），根为 −2 与 3。
  3. 解集：−2 ≤ x ≤ 3。
答：解集为 [−2, 3]。
点拨：开口向上（a>0）时，“≤0 取两根之间、≥0 取两根之外”。含等号则端点取闭。
中 · Medium配凑用均值求最小值考点：凑出定积 + 验等号

题已知 x > 1，求 y = x + 1x−1 的最小值。

解
  1. 配凑出可用均值的两项：y = (x − 1) + 1x−1 + 1。
  2. 因 x > 1，(x−1) > 0，由均值 (x−1) + 1x−1 ≥ 2√1 = 2。
  3. 故 y ≥ 2 + 1 = 3，等号 ⇔ x−1 = 1x−1 ⇒ x = 2。
答：最小值为 3（当 x = 2 时取得）。
点拨：见 x−1 作分母就把 x 拆成 (x−1)+1，凑出乘积为定值的两项。一定要验证等号能取到，否则最小值不成立。
难 · Difficult“1”的代换考点：约束条件整体乘入

题已知 x > 0，y > 0，且 1x + 9y = 1，求 x + y 的最小值。

解
  1. 把目标乘以等于 1 的约束：x + y = (x + y)(1x + 9y)。
  2. 展开：= 1 + 9xy + yx + 9 = 10 + (9xy + yx)。
  3. 由均值 9xy + yx ≥ 2√9 = 6，故 x+y ≥ 16。
  4. 等号 ⇔ 9xy = yx ⇒ y = 3x；代回约束 1x+3x=1 ⇒ x = 4，y = 12。
答：最小值为 16（当 x = 4，y = 12 时取得）。
点拨：凡给出“? + ? = 1”这类约束求另一式最值，一律用“1”的代换：目标 ×（=1 的式子）再展开，交叉项用均值。切勿分别取两项最小——那样等号不能同时成立，会得到错误的更小值。

易 · Easy圆锥体积与侧面积考点：勾股求高

题圆锥底面半径 r = 3，母线 l = 5。求它的体积与侧面积。

解
  1. 高 h = √(l2 − r2) = √(25 − 9) = 4。
  2. 体积 V = 13πr2h = 13π·9·4 = 12π。
  3. 侧面积 S侧 = πrl = π·3·5 = 15π。
答：体积 12π，侧面积 15π。
点拨：圆锥中 母线2 = 半径2 + 高2（轴截面直角三角形）。别把母线当高代进体积。
中 · Medium线面垂直证明考点：两相交线垂直

题在正方体 ABCD-A1B1C1D1 中，求证：BD ⊥ 平面 ACC1A1。

解
  1. 底面 ABCD 是正方形，对角线互相垂直：BD ⊥ AC。
  2. AA1 ⊥ 底面 ABCD，而 BD ⊂ 底面，故 AA1 ⊥ BD。
  3. AC 与 AA1 是平面 ACC1A1 内两条相交直线（交于 A），且都与 BD 垂直。
  4. 由线面垂直判定定理，BD ⊥ 平面 ACC1A1。
得证。
点拨：证“线⊥面”必须凑齐面内两条相交直线都与该线垂直——缺“相交”二字就扣分。一条来自底面对角线性质，一条来自侧棱⊥底面，是正方体里的黄金组合。
难 · Difficult空间向量求二面角考点：建系 + 两法向量夹角

题四棱锥 P-ABCD 中，底面 ABCD 为正方形，边长 2，PD ⊥ 底面 ABCD，PD = 2。求二面角 A-PB-C 的余弦值。

解
  1. 以 D 为原点，DA、DC、DP 为 x,y,z 轴建系：D(0,0,0)，A(2,0,0)，B(2,2,0)，C(0,2,0)，P(0,0,2)。
  2. 平面 PBA 的法向量 n1：由 PA=(2,0,−2)、PB=(2,2,−2) 叉乘得 n1 = (4, 0, 4)（可取 (1,0,1)）。
  3. 平面 PBC 的法向量 n2：由 PC=(0,2,−2)、PB=(2,2,−2) 叉乘得 n2 = (0, −4, −4)（可取 (0,1,1)）。
  4. cos⟨n1,n2⟩ = 1·0 + 0·1 + 1·1√2 · √2 = 12。
  5. 观察图形，二面角 A-PB-C 为钝角，故其余弦取负：−12。
答：二面角 A-PB-C 的余弦值为 −½（即二面角为 120°）。
点拨：有一条棱垂直底面时优先建系，把几何问题变成算法向量。法向量夹角的余弦只给出“±”，最终正负要结合图形判断二面角是锐还是钝——这是最常见的失分点。

易 · Easy椭圆离心率考点：c²=a²−b²

题求椭圆 x29 + y25 = 1 的离心率。

解
  1. a2 = 9，b2 = 5，则 c2 = a2 − b2 = 4，c = 2，a = 3。

中 · Medium由渐近线与过点定双曲线考点：b/a 关系 + 代点

题中心在原点、焦点在 x 轴上的双曲线，渐近线为 y = ±√3 x，且过点 (2, 3)。求其标准方程。

解
  1. 设方程 x2a2 − y2b2 = 1。渐近线 y=±bax = ±√3x ⇒ b2 = 3a2。
  2. 过点 (2,3)：4a2 − 9b2 = 1。代 b2=3a2：4a2 − 93a2 = 4a2 − 3a2 = 1a2 = 1。
  3. ⇒ a2 = 1，b2 = 3。
答：双曲线方程为 x2 − y23 = 1。
点拨：已知渐近线的双曲线可设 x2−y23=λ（λ≠0），代点求 λ 更快，能自动满足渐近线且免去焦点在哪轴的讨论。
难 · Difficult直线与椭圆：垂直 → 定值考点：联立、韦达、点到线距

题椭圆 C：x24 + y2 = 1，直线 l：y = kx + m 交 C 于 A、B 两点，且 OA ⊥ OB（O 为原点）。求证：原点 O 到直线 l 的距离为定值。

解
  1. 联立并整理（乘 4）：(1 + 4k2)x2 + 8kmx + 4(m2 − 1) = 0。
  2. 韦达：x1+x2 = −8km1+4k2，x1x2 = 4(m2−1)1+4k2。
  3. OA⊥OB ⇒ x1x2 + y1y2 = 0。又 y1y2 = (kx1+m)(kx2+m) = k2x1x2 + km(x1+x2) + m2。
  4. 代入 ⇒ (1+k2)x1x2 + km(x1+x2) + m2 = 0。乘 (1+4k2) 展开、化简得 5m2 = 4 + 4k2，即 m2 = 4(1+k2)5。
  5. 原点到 l（kx−y+m=0）距离 d = |m|√(k2+1) = √(4(1+k2)/5)√(1+k2) = √45 = 2√55。
答：d = 2√5 / 5，为定值（与 k、m 无关）。
点拨：解几压轴通法：设线—联立—韦达—代条件。“OA⊥OB”翻译成 x1x2+y1y2=0，再用韦达把 y1y2 换成 x 的对称式。定值/定点题的信号是“证明与参数无关”——算到最后参数应自动约掉。（另需说明直线斜率不存在的情形同样成立。）

概率与统计

Probability & Statistics

基础知识 · Core knowledge

古典概型
P(A) = A 含样本点数样本空间总数，需等可能。计数常配合排列组合。
条件概率与全概率 新增
条件概率 P(B|A) = P(AB)P(A)。全概率 P(B) = Σ P(Ai)P(B|Ai)。贝叶斯 P(Ai|B) = P(Ai)P(B|Ai)P(B)。
随机变量的分布与期望
E(X)=Σxipi。二项分布 X~B(n,p)：E=np，D=np(1−p)。还有超几何分布、正态分布（关于 μ 对称）。
易 · Easy古典概型考点：组合计数

题袋中有 3 个红球、2 个白球，一次任取 2 个。求恰好取到 1 红 1 白的概率。

解
  1. 总取法：C(5,2) = 10。
  2. 1 红 1 白：C(3,1)·C(2,1) = 3·2 = 6。
  3. P = 610 = 35。
答：概率为 3/5。
点拨：“一次取多个、不讲顺序”用组合 C；分步取（有先后）才用排列或乘法。分类（红的选法 × 白的选法）用乘法原理。
中 · Medium二项分布考点：B(n,p) 的 P、E、D

题某人射击命中率为 0.8，独立射击 3 次，记命中次数为 X。求 P(X = 2) 及 E(X)、D(X)。

解
  1. 各次独立、命中率相同 ⇒ X ~ B(3, 0.8)。
  2. P(X=2) = C(3,2)·0.82·0.21 = 3·0.64·0.2 = 0.384。
  3. E(X) = np = 3·0.8 = 2.4；D(X) = np(1−p) = 3·0.8·0.2 = 0.48。
答：P(X=2) = 0.384，E(X) = 2.4，D(X) = 0.48。
点拨：识别二项分布三要素：独立、重复、每次两种结果且概率不变。记牢 E=np、D=np(1−p)，能省去逐项算分布列。
难 · Difficult全概率公式 + 贝叶斯考点：新增热点

题某产品由甲、乙两条生产线生产，甲线占总产量 60%、次品率 2%，乙线占 40%、次品率 3%。
(1) 任取一件，求它是次品的概率；(2) 已知取到的是次品，求它来自甲线的概率。

解
  1. 记事件 甲、乙 为来源，B 为“次品”。P(甲)=0.6，P(乙)=0.4，P(B|甲)=0.02，P(B|乙)=0.03。
  2. (1) 全概率：P(B) = P(甲)P(B|甲) + P(乙)P(B|乙) = 0.6·0.02 + 0.4·0.03 = 0.012 + 0.012 = 0.024。
  3. (2) 贝叶斯：P(甲|B) = P(甲)P(B|甲)P(B) = 0.0120.024 = 12。
答：(1) 次品概率 0.024；(2) 次品来自甲线的概率 1/2。
点拨：“先分几种来源、再求最终结果概率”是全概率（正着乘、按来源加）；“已知结果反推来源”是贝叶斯（分子是某一支、分母是全概率）。画树状图（0.6→0.02…）能防止把条件概率与联合概率搞混。这是新课标新增、近年大题的高频考法。

易 · Easy二项式指定项系数考点：通项定 k

题求 (x + 2)5 的展开式中 x3 的系数。

解
  1. 通项 Tk+1 = C(5,k)·x5−k·2k。
  2. 令 x 的幂 5 − k = 3 ⇒ k = 2。
  3. 系数 = C(5,2)·22 = 10·4 = 40。
答：x3 的系数为 40。
点拨：先写通项，用“x 的指数 = 目标”定出 k，再算系数（别漏常数项里的 2k）。“系数”含数字因子，“二项式系数”只指 C(n,k)。
中 · Medium排列组合：不相邻考点：插空法

题3 名男生、2 名女生排成一排，要求 2 名女生不相邻。求不同排法的种数。

解
  1. 先排 3 名男生：A(3,3) = 6 种，形成 4 个“空档”（含两端）。
  2. 再把 2 名女生插入这 4 个空档且各占其一（自动保证不相邻）：A(4,2) = 12 种。
  3. 由分步乘法：6 × 12 = 72。
答：共 72 种排法。
点拨：不相邻 → 插空（先排其余元素，再往空里插）；相邻 → 捆绑（先把相邻的绑成一个整体，别忘内部还要排 A(2,2)）。两招是排列应用题的主力。
难 · Difficult新定义：取整函数求和考点：读定义 + 分段计数

题对实数 x，记 [x] 为不超过 x 的最大整数（如 [2.3]=2，[3]=3）。设 f(n) = [log2n]（n∈N*）。求 f(1) + f(2) + … + f(15)。

解
  1. 理解定义：f(n) = [log2n]，即“n 落在 [2m, 2m+1) 时 f(n)=m”。
  2. 分段：n=1 → f=0（1 个）；n=2,3 → f=1（2 个）；n=4,…,7 → f=2（4 个）；n=8,…,15 → f=3（8 个）。
  3. 求和 = 0·1 + 1·2 + 2·4 + 3·8 = 0 + 2 + 8 + 24 = 34。
答：f(1)+…+f(15) = 34。
点拨：新定义题第一步永远是把定义读懂、代几个小值试探（[log₂1]=0、[log₂4]=2…），发现“同值成段”的规律后按段计数再乘以段内个数。心态上别被陌生符号吓退——它一定是用你已会的知识包装出来的。
