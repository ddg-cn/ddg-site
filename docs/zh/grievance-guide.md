# 申诉渠道

**合作之前、合作期间和合作结束之后，职工如何反映问题，以及怎样判断有没有人在听**

*简明指南，2026年11月第1版。适用于买方、审核员和供应商工厂，特别是在中国的工厂。本文属于系列指南之一：[业务关系生命周期](/zh/ddg#_0-8-各指南的位置-业务关系的生命周期)的第五阶段，同时贯穿其他各个阶段。*

::: tip 一分钟读懂
1. **职工知道、信任并且看到结果，渠道才算真的存在。** 墙上挂一个意见箱、登记簿上一片空白，什么也证明不了。
2. **零投诉是警示信号，不是合格。** 渠道变得更容易使用时，投诉数量首先会上升。
3. **在中国，基本的组成部分早已具备：** 企业劳动争议调解委员会、工会、12333、劳动保障监察和免费的劳动仲裁。好的渠道要与它们衔接，绝不能要求职工放弃这些途径。
4. **买方也需要申诉渠道。** 按照欧盟和德国法律，企业必须提供一条能让供应商职工使用的投诉途径，并在退出后继续保持开放。
5. **要核实，不要想当然。** 用第6章的检查清单：追踪真实案例，询问职工，发一条测试信息。
:::

## 1. 渠道为什么会失灵

| 证据 | 发现 |
|---|---|
| SOMO（荷兰跨国企业研究中心）与GoodElectronics，中国和另外四个国家的40家电子厂（2014年） | 很少有职工信任企业的申诉机制；大多数人不知道投诉如何处理；合同工常常被排除在外 |
| 孟加拉国Amader Kotha热线（2014–2026年约52万次来电） | 只有 **22%** 的来电者愿意向工厂透露姓名，而愿意向独立热线透露姓名的达 **85%** |
| ETI（道德贸易倡议）关于西班牙和意大利外来农业工人申诉机制的研究 | "对正式申诉制度普遍不信任"；申诉机制宣传不到位，难以使用 |
| Better Work，柬埔寨41家工厂（2025年） | 培训后，职工对申诉机制的了解从 **31%** 上升到 **93%**：知晓程度是可以改善的 |
| 经合组织（OECD）国家联络点（2023年） | 已结案件中52%达成了协议，但平均耗时 **962天**。此前一项NGO的评估发现，250个案件（2000–2015年）中只有约1%让受害者得到了补救。 |

**一个中国的例子。** 2002年，几个品牌和一家采购代理商为广东约500家供应商的职工开通了一条热线，把投诉转给劳动部门和法律援助机构。由于担心带来负面形象，这些企业叫停了热线。2007年推出的保密版本在五年内处理了1,055个案件，12小时内答复，管理人员反映员工流失率下降。启示是：渠道既要足够安全，让职工敢用；也要足够让人接受，让工厂愿意保留。*（Hofman、Wu和Liu，《当代中国事务杂志》，2014年。）*

## 2. 管用的渠道是什么样的：八项标准

联合国《工商企业与人权指导原则》（2011年，原则31）为非司法申诉机制规定了八项有效性标准。此后所有标准都沿用这八项。

| 标准 | 通俗地说 | 看什么 |
|---|---|---|
| **正当性** | 得到使用者的信任 | 不由被投诉的人负责处理；有职工代表参与 |
| **可及性** | 所有使用者都知道，而且用得上 | 有多种途径，使用当地语言，免费，覆盖中介招聘工和劳务派遣工 |
| **可预测性** | 程序清楚，有时限 | 有书面的处理环节和期限，并且按期完成 |
| **公平性** | 投诉人能获得信息和咨询 | 可以找工会、法律援助或顾问 |
| **透明度** | 让投诉人了解进展 | 确认收到、通报进展、给出附理由的处理结果 |
| **权利兼容性** | 处理结果符合人权和法律 | 绝不要求职工放弃法定权利或其他救济途径 |
| **持续学习的来源** | 从中吸取的经验改变了做法 | 每年复核；向管理层报告趋势 |
| **以参与和对话为基础** | 与使用者一起设计和复核 | 设计时征求职工意见；结案后询问满意度 |

综合各方资料，职工真正愿意使用一条渠道的原因是：他们用自己的语言知道它的存在；既有指定的可信任人员，也有匿名途径；处理结果看得见；有工会或第三方参与；不花钱；用过的人没有受到惩罚；只有一条统一协调的渠道，而不是多条互相竞争的渠道。

## 3. 法律有哪些要求

| 法律 | 年份 | 要求 |
|---|---|---|
| **欧盟《企业可持续发展尽职调查指令》（CSDDD）**第14条，经"综合简化"一揽子法案（Omnibus I）修订 | 2024 / 2026（2029年7月起适用） | 设立投诉程序，向整个活动链上受影响的人和职工代表开放，另设任何人都可使用的通报机制。投诉人可以要求跟进、要求与企业会面，并获知处理结果。*（2026年对该条的修订，本指南仍在核对中。）* |
| **德国《供应链尽职调查法》（LkSG）**第8条 | 2023 | 投诉程序须覆盖企业自身业务和供应商的职工；处理人员须公正、保密；公开程序；每年复核。*（修正草案仍在联邦议院审议中。）* |
| **欧盟《举报人保护指令》**（EU）2019/1937 | 2019 | 50名以上员工的组织须设立内部举报渠道；7天内确认收到；3个月内反馈；禁止报复 |
| **中国《劳动争议调解仲裁法》** | 2008 | 先协商，再调解，然后仲裁，最后诉讼（第5条）。申请仲裁的时效为一年（第27条；劳动关系存续期间拖欠劳动报酬的不受此限），劳动争议仲裁不收费（第53条）。 |
| **中国《企业劳动争议协商调解规定》（人社部令第17号）** | 2012 | 大中型企业应当设立劳动争议调解委员会（第13条），由职工代表和企业代表人数相等组成（第15条）；3个工作日内决定是否受理（第22条），15日内结束调解（第29条）；建立调解档案（第32条） |
| **中国《工会法》** | 2021年修正（2022年施行） | 工会参与企业劳动争议调解（第29条），对拖欠工资、不安全条件和随意延长工作时间等情况有权要求纠正（第23条）。职工因参加工会活动被解除劳动合同的，恢复工作，或给予本人年收入二倍的赔偿（第53条）。 |
| **中国《劳动保障监察条例》** | 2004 | 任何组织或个人都可以向劳动保障行政部门举报违法行为，劳动保障行政部门应当为举报人保密（第9条）；违法行为在两年内未被发现的，不再查处（第20条） |
| **中国《个人信息保护法》** | 2021 | 收集投诉数据前履行告知义务（第17条）；向买方提供前取得单独同意（第23条）；健康等敏感个人信息适用更严格的规则（第28–29条）；向境外提供须有合法途径（第38–39条） |

中国没有统一的举报人保护法。相关保护分散在上述各项规定中，因此工厂或买方的申诉渠道必须自行建立禁止报复的保障措施。

**行为准则和项目。** SA8000要求设立保密、公正、禁止报复的投诉程序（2014版第9.6条）。RBA（责任商业联盟）提供RBA Voices；Fair Wear（公平服装基金会）开设了包括中国在内的多条热线，2023年收到新申诉139件；FLA（公平劳工协会）受理第三方投诉，2025年通过调查追回经济补偿30万美元；amfori的Speak for Change目前暂停，等待修订；孟加拉国协议（Bangladesh Accord）已处理4,000多件安全投诉。SLCP（社会与劳工融合计划）的评估在职工参与部分询问申诉制度的情况。

## 4. 合作关系的各个阶段

| 阶段 | 申诉渠道要做到什么 |
|---|---|
| **合作之前** | 在供应商准入时检查其申诉渠道（第6章）。没有有效渠道的工厂会把问题藏起来，日后却要由你来担责。 |
| **合作开始** | 把申诉渠道写进合同：供应商职工可以使用哪个渠道，针对买方自身做法的投诉如何处理，数据如何保护。参见[负责任签约](/zh/contract-guide)。 |
| **合作期间** | 每次审核时查看登记簿和趋势；直接询问职工；某项变化之后投诉增加，应视为渠道在发挥作用的信号。 |
| **合作结束** | 最后一张订单之后约**六个月**内，买方的申诉渠道要继续开放，并让工厂职工知道（ETI 2026年）。退出后的大多数问题（未付经济补偿、社会保险）出现得较晚。参见[负责任退出指南](/zh/exit-guide)。 |
| **结束之后** | 从投诉中得到的经验，用于下一次选择供应商和签订下一份合同。 |

## 5. 申诉政策要点

对工厂来说，一页纸的政策涵盖以下几点，就足以起步。买方的版本还要说明自己的渠道如何覆盖供应商的职工。

1. **目的和范围：** 谁可以投诉（全体职工，包括劳务派遣工、中介招聘工和合同工，以及他们的代表），可以投诉什么（任何违反法律、行为准则或侵犯个人权利的情况）。
2. **渠道：** 当面反映（指定人员）、电话、微信或App、意见箱，以及至少一条不经过直属管理层的途径；有外部渠道的，也要列出。
3. **步骤和时限：** 3个工作日内确认收到；开展调查；尽可能在15日内作出决定；告知投诉人处理结果和理由；可向劳动争议调解委员会、工会或外部机构申诉。
4. **禁止报复与保密：** 善意投诉不受任何惩罚；接受匿名投诉；保护投诉人身份。
5. **个人信息：** 收集哪些信息，谁能看到，保存多久；提供给客户前取得单独同意；只有匿名化处理后的数据才能出境。
6. **保留权利：** 使用申诉渠道绝不取代12333、劳动保障监察、劳动仲裁或诉讼。
7. **记录与复核：** 每个案件都要登记；每年与职工代表一起复核；结果报告管理层，并向职工通报概况。
