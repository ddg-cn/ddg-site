# 🔍 ESG 报告透镜 <Badge type="warning" text="预览版" />

上传可持续发展、ESG 或社会责任报告（PDF），或粘贴报告链接。您会得到一份简短的**解读**（做得好的 / 需要改进的），以及带页码的问题清单，可导出为 Excel 或 CSV。

## 检查内容

| 类型 | 检查什么 |
|------|------|
| **数据** | 报告数据表中对不上的数字：范围一 + 范围二 ≠ 披露的总量；男性 + 女性 ≠ 员工总数；按性别、年龄、地区等划分的占比合计不等于 100%；“其中”项大于合计；百分比超过 100%；同一指标出现两个不同数值；强度 ≠ 总量 ÷ 营收；同比大幅变化但未说明边界或方法变化 |
| **表述** | 需要依据支撑的表述：绝对化表述（零排放、无污染）、未说明范围或认证的碳中和 / 零碳声明、依赖碳抵消、只有远期目标没有中期里程碑、降幅无基准、目标无期限、仅强度下降、100% 可再生、无依据的“领先”、模糊环保标签、边界不完整等。针对特定对象的表述（如*废水*零排放）或报告其他位置有支持信息时，优先级会降低；ZDHC 等公认项目名称不会被标记 |
| **缺失** | 119 项指标，对应交易所《可持续发展报告指引》（2024）、GRI 与 ISSB S2。关键缺失：范围一 / 范围二数据、第三方鉴证、重要性评估、温室气体核算方法与基准年、报告边界 |
| **跨年** | 提供去年的报告时：消失或不再量化的指标、未加重述说明而被改动的往年数值、不再提及的目标 |

**交易所指引覆盖**得分只计与交易所指引相关的指标（已披露 = 1，部分 = ½）。

## 如何阅读结果

- **高 / 中** = 优先查看 · **低** = 值得核对 · **提示** = 背景信息（默认隐藏，点击标签可显示）。
- 点击某一行可查看“为什么重要”和“更好的做法”。
- 每个问题都标注了页码。引用前请打开原页核对：这是自动筛查，不是审计意见。

::: info 隐私
PDF 在**您的浏览器中**读取（pdf.js）并完成分析（WebAssembly 中运行的 Python），报告不会被上传或保存。粘贴链接时，由于巨潮资讯等报告网站不允许其他网站直接下载文件，文件会通过 scdd.pro 的中转服务以 4 MB 分段传输，不做任何保存。
:::

::: warning 局限
- 暂不能读取扫描版 PDF（没有文字层的图片）。
- 数字核对依赖数据表；只以图表或图片呈现的数据无法核对。
- 覆盖检查基于关键词：只说明报告提到了某个议题，不代表披露质量好。
:::
