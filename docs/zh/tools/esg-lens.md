## 检查内容

| 类型 | 检查什么 |
|------|------|
| **数据** | 报告数据表中对不上的数字：范围一 + 范围二 ≠ 披露的总量；男性 + 女性 ≠ 员工总数；按性别、年龄、地区等划分的占比合计不等于 100%；“其中”项大于合计；百分比超过 100%；同一指标出现两个不同数值；强度 ≠ 总量 ÷ 营收；同比大幅变化但未说明边界或方法变化 |
| **表述** | 需要依据支撑的表述：绝对化表述（零排放、无污染）、未说明范围或认证的碳中和 / 零碳声明、依赖碳抵消、只有远期目标没有中期里程碑、降幅无基准、目标无期限、仅强度下降、100% 可再生、无依据的“领先”、模糊环保标签、边界不完整等。针对特定对象的表述（如*废水*零排放）或报告其他位置有支持信息时，优先级会降低；ZDHC 等公认项目名称不会被标记 |
| **缺失** | 119 项指标，对应交易所《可持续发展报告指引》（2024）、GRI 与 ISSB S2。关键缺失：范围一 / 范围二数据、第三方鉴证、重要性评估、温室气体核算方法与基准年、报告边界 |
| **跨年** | 添加去年的报告时（第 2 步，或检查完成后点“与去年的报告对比”）：消失或不再量化的指标、未加重述说明而被改动的往年数值、不再提及的目标 |

## 对照的标准

可以自选对照标准，也可以保留“**按报告声明采用的标准**”：工具会识别报告声明参照的标准（如“参照 GRI 标准编制”），并据此检查；报告未声明的，默认对照交易所指引与 GRI。

| 标准 | 类型 | 条款数 |
|------|------|------|
| 交易所《可持续发展报告指引》（2024）—— 上交所第14号 / 深交所第17号 / 北交所第11号 | 交易所规则 | 50 |
| GRI 标准（GRI 2、3 及议题标准） | 报告准则 | 94 |
| ISSB（IFRS S1 / S2） | 报告准则 | 22 |
| 港交所《环境、社会及管治报告守则》（附录 C2） | 交易所规则 | 50 |
| IFC 绩效标准 | 参考视角——为融资项目制定，并非报告准则，得分通常偏低 | 26 |
| 评级机构关键议题 | 参考视角——依据 MSCI 等评级机构公开的关键议题清单整理；**不是 MSCI 评级**，与任何评级机构无关；行业特定议题只显示、不计分 | 32 |

每个标准单独计分（已披露 = 1，部分 = ½），缺失项会注明要求它的条款（如 *GRI 305-3 · 港交所 D Scope 3*）。TCFD 与 SASB 可识别，暂不计分。

**GRI 内容索引核对。** 报告附有 GRI 内容索引时，逐条检查：索引说已披露的，报告中是否有相应内容？索引给出页码的，还会推算印刷页码与 PDF 页码的差，核对所引页面（± 1 页）是否确有该内容。索引中说明从略的条目只计数，不标记。

## 内容评级

评级（A–E）评的是**报告本身的披露质量**：是否完整、一致、可验证，不评价公司的 ESG 表现。共六项，每项 0-100 分，按权重合计：

| 项目 | 权重 | 依据 |
|------|------|------|
| 覆盖面 | 20% | 所选报告准则与交易所规则得分的平均值（两个参考视角只显示、不计入平均），并分别显示环境 / 社会 / 治理 |
| 数据深度 | 20% | 有数据的定量指标占比、数据表数值数量、多年对比；去年有今年没有的内容会扣分 |
| 数字一致 | 20% | 通过的算术核对与发现的数字问题，以及 GRI 内容索引的错误；可核对的内容太少时不评分 |
| 表述有依据 | 15% | 高 / 中 / 低风险表述标记，以及模糊承诺用语的密度 |
| 目标质量 | 10% | 带年份的量化近期目标；无基准、无期限、只有远期目标的标记 |
| 可验证性 | 15% | 第三方鉴证、温室气体核算方法 / 基准年、报告边界、重要性评估 |

A ≥ 85 · B ≥ 70 · C ≥ 55 · D ≥ 40 · E 低于 40。每一项都显示得分理由，方便对照报告核对。

## 如何阅读结果

- **高 / 中** = 优先查看 · **低** = 值得核对 · **提示** = 背景信息（默认隐藏，点击标签可显示）。
- 点击某一行可查看“为什么重要”和“更好的做法”。
- 每个问题都标注了页码。引用前请打开原页核对：这是自动筛查，不是审计意见。

::: info 隐私
PDF 在**您的浏览器中**读取（pdf.js）并完成分析（WebAssembly 中运行的 Python），报告不会被上传或保存。粘贴链接时，由于巨潮资讯等报告网站不允许其他网站直接下载文件，文件会通过 scdd.pro 的中转服务以 4 MB 分段传输，不做任何保存。
:::

::: warning 局限
- 暂不能读取扫描版 PDF（没有文字层的图片）。
- 数字核对依赖数据表；只以图表或图片呈现的数据无法核对。
- 覆盖检查基于关键词：只说明报告提到了某个议题，不代表披露质量好。
:::
