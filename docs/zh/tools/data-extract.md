# 🗂️ 报告数据提取 <Badge type="warning" text="预览" />

一次拖入多份报告，按**报告类型各生成一张表**并下载为 Excel：每份报告一行（字段自选），另有每个发现、目标或数据集一行的明细表。可用于比较供应商、建立跟踪表，或把审核结果导入自己的系统，无需手工录入。

::: info 不上传、不保存
文件在您的浏览器中读取，网站不会接收或保存；Excel 文件在您的电脑上生成。所选字段只记在本浏览器中。

## 支持的报告

| 报告类型 | 文件 | 每份报告一行（示例） | 每项一行 |
|---|---|---|---|
| Clarity（必维） | PDF | 工厂、模块、报告编号、完成日期、总分、不符合项数、各章节得分和不符合项 | 不符合项：检查点、问题、备注、状态、日期 |
| RBA VAP | PDF（完整或摘要） | 审核编号、工厂、机构、日期、得分、估算得分、按严重程度和章节的不符合项数、工人数 | 不符合项：问题、章节、评级、法律不符合、结论 |
| SMETA | PDF（审核报告或 CAPR） | Sedex 编号、工厂、审核类型和支柱、日期、审核机构、工人数、不符合项数 | 不符合项：条款、描述、证据、纠正措施、状态 |
| amfori BSCI | PDF | amfori ID、工厂、日期、总评级和各领域评级、工人数 | 发现：绩效领域、问题、评级、描述 |
| EcoVadis | PDF（问卷导出） | 范围、完成的问题数、各主题附件数、KPI 和目标数 | KPI 数值：问题、指标、年份、数值、单位 |
| CDP | PDF（问卷导出或评分报告） | 组织、营业收入、报告年度、范围一/二/三、目标；或得分和等级段 | 减排目标：类型、科学碳目标、基准年和目标年、减排比例、状态 |
| SLCP | .xlsm（核查或工厂工具 1.7.x） | 工厂、OS ID、国家、步骤、准确性指数、工人数、核查日期和机构，以及工具中的**任意问题** | 不准确或不合规的回答：工厂回答、核查员选择和回答、说明 |
| 碳足迹 | .xlsx（欧盟电池碳足迹报告模板、生命周期清单数据表） | 表格类型、产品、供应商、数据集、超出参考范围的因子 | 数据集：组件、排放因子、数据库、地理、填报和建议的 TeR/GeR/TiR/P |

## 使用方法

1. 一次拖入全部文件（可混合类型），之后也可继续添加。
2. 选择报告类型标签，为每张表勾选字段。可搜索字段；**默认**恢复标准字段。SLCP 工具的全部问题按章节列出，可只添加您跟踪的回答。
3. 查看预览后点击**下载 Excel**。每张表一个工作表，已开启筛选。**下载 Excel（全部类型）**把所有类型放在一个工作簿中。

::: warning 请注意
字段依据报告的文字排版读取，特殊模板或扫描页可能导致字段为空。重要数值请与原报告核对。使用数据前，可先用对应的[质检工具](/en/tools.html)检查报告错误。界面字段名部分为英文。
:::
