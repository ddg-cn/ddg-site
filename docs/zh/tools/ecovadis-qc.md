把 **EcoVadis 问卷** 下载为 PDF（*Survey Full*），提交前拖到下方检查。程序检查问题状态、所附文件和 KPI 数值。

PDF 在您的浏览器中读取，不会上传到任何服务器。首次检查需下载约 1 MB 的 PDF 读取组件，之后浏览器会缓存。

## 结果说明

- **错误** = 必须修改 · **警告** = 需要复核 · **提示** = 供参考。
- 点击数量可按严重程度筛选；也可按规则或文件筛选，或搜索编号、页码、内容。
- **页** 为 PDF 页码；**编号** 为该问题所涉及的问题、检查点或章节。问题说明目前为英文。
- **下载 Excel 报告** 包含相同清单（汇总、问题、规则三个工作表），便于分享和跟踪整改。

## 检查内容

程序读取每个问题（状态、编号、影响）、每份附件（名称、类型、标注页码、评论）以及每行 KPI（年份、单位、数值）。

| 规则 | 严重程度 | 检查 |
|------|----------|------|
| EV-01 | 错误 | 问题未完成（状态为 Mandatory / Incomplete） |
| EV-02 | 错误 | 附件未标注页码 |
| EV-03 | 警告 | 标注的页码范围过宽或格式错误 |
| EV-04 | 警告 | 文件名或评论不是英文（评审员可能无法阅读） |
| EV-05 | 警告 | 文件名包含内部备注（如“解密”“草稿”“副本”“测试”） |
| EV-06 | 提示 | 同一文件被附在多个问题下（请确认确实覆盖各主题） |
| EV-07 | 提示 | 文件类型为“Other”（选择具体类型便于评审） |
| EV-08 | 错误 | KPI：填写了年份但没有数值 |
| EV-09 | 警告 | KPI 数值不合理（百分比超过 100、负数、计数带小数、比率按百分比填写） |
| EV-10 | 警告 | KPI 年份早于两年前，或目标年份已过 |
| EV-11 | 警告 | “Other”选项附了文件但“Please specify”为空 |
| EV-12 | 警告 | 同一答案选项下重复附同一文件 |
| EV-13 | 提示 | 某主题的支持文件很少 |
| EV-14 | 警告 | 占位符或未完成的文字 |
| EV-15 | 提示 | 文件评论说明了缺口或证据不完整 |
