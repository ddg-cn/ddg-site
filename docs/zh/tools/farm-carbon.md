# 🥬 农产品碳足迹计算器 <Badge type="warning" text="预览" />

快速估算蔬菜、水果、茶叶和粮食的**农场大门**碳足迹。选择作物，按亩或公顷填入实际用量（化肥、柴油、电、农膜），即可得到每公斤产品的 kg CO2e、主要排放来源，并可下载包含投入、结果和因子的 Excel 表。

## 计算方法

边界：一个生长季的**摇篮到农场大门**——投入品生产加田间排放；不含包装、预冷、运输、土地利用变化和土壤碳变化。

| 部分 | 计算方式 |
|---|---|
| 化肥生产 | 折纯量 × 因子。中国氮肥因子取自 Zhang 等 2013（PNAS，经后续研究引用）：尿素 8.1、复合肥 7.4、碳铵 7.2 kg CO2e/kg N；P2O5 1.5；K2O 0.7 |
| 田间直接 N2O | IPCC 2019 表 11.1：EF1 = 0.016（化肥氮，湿润气候）、0.006（有机氮和秸秆，湿润）、0.005（干旱气候）、0.004（淹水稻田）kg N2O-N/kg N |
| 间接 N2O | 挥发：FracGASF 尿素 0.15、铵态氮 0.08、硝铵 0.05，有机肥 0.21；EF4 0.014（湿润）/0.005（干旱）。淋溶：FracLEACH 0.24（湿润或灌溉，否则为 0）× EF5 0.011（IPCC 2019 表 11.3） |
| 尿素 CO2 | 每吨尿素 0.20 吨碳 × 44/12（IPCC 2006 公式 11.13） |
| 石灰 | 每吨石灰石 0.12 吨碳（0.44 kg CO2/kg），另加开采加工 |
| 稻田甲烷 | EF = EFc × SFw × SFp × SFo × 天数。东亚 EFc 1.32 kg CH4/公顷/天；SFw：持续淹水 1.00、单次排水 0.71、多次排水 0.55；SFp：<180 天 1.00、>180 天 0.89、淹水 >30 天 2.41；SFo = (1 + Σ 用量 × CFOA)^0.59，秸秆 <30 天 1.00、>30 天 0.19、厩肥 0.21、绿肥 0.45（IPCC 2019 表 5.11–5.14） |
| 燃油、电、农膜、农药 | 柴油 3.0 kg CO2e/升、汽油 2.7/升（IPCC 燃烧 + 上游）；电力 0.5777 kg CO2e/kWh（生态环境部 2024 年全国电力碳足迹因子）；PE 农膜 2.5/kg；农药 15/kg 有效成分 |
| 全球增温潜势 | IPCC AR6 100 年：CH4 27.0，N2O 273 |

所有投入品因子都可在**修改因子**中调整，例如改用供应商自己的化肥碳足迹或省级电网因子。

## 小贴士

- 多数蔬菜水果的碳足迹以**氮肥**为主：化肥生产加田间 N2O。按作物需求控制施氮量通常是最大的减排抓手。
- **水稻不同**：稻田甲烷通常占大头，烤田、干湿交替可以大幅降低。
- 结果为**筛查性估算**（IPCC 一级方法）。用于标签或对客户声明时，需按 ISO 14067 依据实测农事记录开展研究并经评审。
