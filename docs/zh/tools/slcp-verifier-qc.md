# 🧪 SLCP 核查工具质检器

适用于 **SLCP 离线核查工具（Verifier Tool）2.0.0**。核查员在提交前将已填写的 `.xlsm` 文件拖到程序上，即可得到一份 Excel 质检报告，逐条列出需要修改或复核的输入。工具文件本身不会被修改。

[⬇️ 下载 v1.1（zip，约 34 KB）](/downloads/tools/slcp-verifier-qc-checker-v1.1.zip)

## 快速开始

需要 Python 3.9+ 和 `openpyxl`：

```bash
py -m pip install openpyxl
```

- **拖放：** 将一个或多个已填写的 `.xlsm` 文件拖到 `Run Quality Checker.bat` 上。
- **命令行：** `py vt_quality_checker.py "<工具文件>.xlsm" [-o "<报告>.xlsx"]`

报告保存在工具文件旁，文件名为 `<工具名> - QC Report <yymmdd>.xlsx`，包含三个工作表：

| 工作表 | 内容 |
|------|------|
| **Summary** | 按规则统计的问题数量，以及在当前模板上无法运行的规则 |
| **Issues** | 每个问题一行：严重程度、规则、题号、Key；*Tool Row* 链接可直接跳到工具中的对应行（报告需与工具放在同一文件夹） |
| **Rules** | 完整规则目录 |

严重程度：**Error** = 必须修改 · **Warning** = 需要复核 · **Info** = 提示。

## 检查内容

| 规则组 | 编号 | 说明 |
|------|------|------|
| 语言 | LANG-01..04 | 核查数据、更正答案和核查员填写的答案须为英文（营业执照所用当地语言的题目除外）；工厂用其他语言作答时不能选 *Accurate* |
| 核查选项 | SEL-01..16 | *Accurate* 不应有更正答案；*Inaccurate* / *Updated* 需有不同于工厂答案的更正答案及核查数据；*Not visible* 时工厂答案应为空；*No longer applicable* 不应有更正或核查数据；有工厂答案就要有核查选项；选项须在该题的列表中 |
| 数据类型 | DATA-01..08 | 整数、非负数、0–100 %、经纬度范围及是否落在工厂所在国家、YYYY-MM-DD 日期、答案在选项列表中、复选框只能为 X |
| 法律标记 | LEGAL-01..05 | 标记 X 需有法律依据；违规答案需标记 X 并附法律依据；合规答案或“无适用法律要求”不应标记 X |
| 特定问答 | SPEC-01..20 | 60 小时与休息日、强迫与自愿加班、起止日期、认证与分包商重复、最小工人年龄、产量与产能、联系人与电话、监狱劳工、骚扰案例、工时阈值、抽样数据与答案矛盾、OS ID 格式等 |
| 关联逻辑 | REL-01..06 | 父题答案不触发时子题却已作答；“以上皆非”与其他选项同时勾选；分项大于总数（如男工 > 总工人数）；不合理比例；可见题目未作答 |
| 合理性 | PLAUS-01..04 | 国籍数、语言数或工资等级为 0；最长交货期超过 52 周；仅一个性别的工资为 0；人均建筑面积低于 2 m² |

## v1.1：用真实报告校准规则

一条规则如果在大量真实、已核查的报告中都会触发，问题更可能出在规则本身。v1.1 用 **1,000 份随机抽取并已匿名化的平台核查报告（VRF，工具版本 1.4–1.7.1）** 测试了各项关联与合理性规则，并据此调整：

| 规则 | 校准前触发率 | 调整 | 校准后 |
|------|------|------|------|
| OSH 委员会：雇主代表 + 工人代表 ≠ 总人数 | 37 % | 委员会常有其他成员，仅在“大于总人数”时报告 | 3 % |
| 实得工资低于基本工资 | 18 % | 扣款很常见，改为低于基本工资 80 % 时报告 | 6 % |
| 最大工会会员数 > 总工人数 | 13 % | 由 Error 改为 Warning | — |
| 有法律依据但未标记 X | 60 % | 由 Warning 改为 Info | — |
| 新增 PLAUS-01..04 | — | — | 每条 0.1–3.4 % |

分析时还发现，数据中大多数“分项 > 总数”的情况来自已隐藏题目里残留的旧数值。质检器只检查当前适用的题目，因此不会误报。

::: info 数据与隐私
校准只使用汇总后的触发率。分析前所有报告都已在本地匿名化：工厂、核查机构和人员信息全部被替换或删除，原始数据不离开本机。下载包中不含任何工厂、核查员或报告数据。
:::

## 维护说明

- 特定问答与关联规则中的题目 Key 按 2.0.0 版本写入。若后续版本删除了某个 Key，相关规则会被跳过，并在 Summary 表的 *Notes* 中列出，不会导致程序出错。
- 阈值是 `vt_quality_checker.py` 顶部的常量，可按需修改。
- `tests/test_qc.py` 会向已填写的工具逐条注入错误，检查对应规则是否触发（v1.1 共 76 项测试）：`py test_qc.py "<已填写工具>.xlsm"`。

::: warning 使用前请注意
本工具用于辅助核查员自查，**不替代** SLCP 核查规程或核查机构的质量审核，结果仅供参考。
:::
