# 🧭 SMETA 审核报告质检 <Badge type="warning" text="预览" />

把 Sedex 平台上的 **SMETA 审核报告**和/或**纠正措施计划报告（CAPR）**拖到下方，检查发现汇总、发现明细、工人数据、工资工时数据和日期是否前后一致。同时选择同一审核的报告和 CAPR，会对两者进行比对。

</ClientOnly>

::: info 文件不会离开您的电脑
PDF 在您的浏览器中读取，不会上传到任何服务器。首次检查需下载约 1 MB 的 PDF 读取组件，之后浏览器会缓存。
:::

## 结果说明

- **错误** = 必须修改 · **警告** = 需要复核 · **提示** = 供参考。
- 点击数量可按严重程度筛选；也可按规则或文件筛选，或搜索编号、页码、内容。
- **页** 为 PDF 页码；**编号** 为该问题所涉及的条款、问题或发现编号。问题说明目前为英文。
- **下载 Excel 报告** 包含相同清单（汇总、问题、规则三个工作表），便于分享和跟踪整改。

## 检查内容

| 规则 | 严重程度 | 检查 |
|------|----------|------|
| SMETA-01 | 错误 | 关键审核或工厂字段缺失（编号、工厂、审核机构、日期、审核类型、支柱、主审核员、APSCA 编号、声明） |
| SMETA-02 | 错误 | 审核日期顺序错误或不合理（审核日期与开始/结束日期、声明日期、进出时间、审核天数） |
| SMETA-03 | 警告 | 编号格式错误（ZAA / ZS / ZC / ZAF）或页脚与审核信息不一致 |
| SMETA-04 | 提示 | 发现编号为空（“ZAF-”）：PDF 在发现提交到 Sedex 之前生成 |
| SMETA-05 | 错误 | 发现汇总与发现明细不一致（缺少发现、类型、条款、工作场所要求、当地法律标记） |
| SMETA-06 | 错误 | 各条款章节的汇总与总体发现汇总不一致 |
| SMETA-07 | 错误 | 不符合项不完整：缺少问题标题、描述、纠正措施、状态、整改期限或验证方式 |
| SMETA-08 | 错误 | 当地法律不符合项缺少法律依据，或当地法律问题未对应任何发现 |
| SMETA-09 | 警告 | 纠正措施只是重复描述或问题标题 |
| SMETA-10 | 警告 | 问题标题与描述矛盾（如标题称“已完成”，描述称“未完成”） |
| SMETA-11 | 警告 | CAPR 时间线：截止日期 ≠ 审核结束 + 整改期限，审核结束前或 PDF 日期之后关闭，或已逾期仍未关闭 |
| SMETA-12 | 错误 | 工人人数加总不一致（男 + 女 = 总数、用工类型、外来工、薪酬类型、百分比） |
| SMETA-13 | 错误 | 工人访谈人数加总不一致或超过工人总数（小组 + 个人、按类型、“N 组每组 M 人”） |
| SMETA-14 | 错误 | 工资、工时或年龄数据显示违规（每周超 60 小时、连续 7 天以上无休、低于法定最低工资、未达法定年龄）但该条款无不符合项 |
| SMETA-15 | 警告 | 工时数据相互矛盾（最长周工时超过正常工时却记录零加班，平均/正常/最长工时不符） |
| SMETA-16 | 警告 | 数据点答案与其备注矛盾，或同一问题在别处答案不同 |
| SMETA-17 | 警告 | 条款章节为“无发现”，但证据描述中提到缺陷 |
| SMETA-18 | 警告 | 环境数据不一致（可再生与不可再生电量相同、各去向废弃物之和超过总量、危废大于总量） |
| SMETA-19 | 警告 | 审核出席：缺席未说明理由，或出席情况与工会/工人代表数据矛盾 |
| SMETA-20 | 警告 | CAPR 签署人与声明中的工厂代表不一致 |
| SMETA-21 | 警告 | 常见拼写错误或重复词 |
| SMETA-22 | 警告 | 占位符或空白文字（条款章节证据为空、“TBC”、选择“提供细节”却未填写） |
| SMETA-23 | 警告 | 同一句话连续重复粘贴 |
| SMETA-24 | 提示 | 有不符合项的条款章节管理体系评级全部为“健全” |
| SMETA-25 | 错误 | 同一审核编号的审核报告与 CAPR 不一致（工厂、日期、审核机构、发现） |
| SMETA-26 | 警告 | 审核支柱与覆盖的条款章节不符（四支柱缺少 10.B / 10.C，或两支柱却包含） |
| SMETA-27 | 错误 | 抽样计算：“X out of Y”中 X > Y，或百分比与 X/Y 不符 |
| SMETA-28 | 提示 | 版式未识别为 SMETA 7 平台报告：仅运行了全文检查 |

::: warning 请注意
适用于 Sedex 平台生成的 SMETA 7 报告。较早的 SMETA 6.x Word 报告只做全文检查（SMETA-28）。关闭证据保存在 Sedex 平台而非 PDF 中，因此已关闭的发现按状态、日期和验证方式检查。本工具为自查辅助，不能替代审核机构的质量审查。
:::
