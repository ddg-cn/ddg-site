# 🌍 CDP 问卷回答质检 <Badge type="warning" text="预览" />

在 CDP 平台导出 **企业问卷回答** 并保存为 PDF，提交前拖到下方检查。导出文件不含未作答的问题，所以程序也会列出缺失的核心问题。CDP 评分报告可以识别并汇总，但其中没有可检查的内容。

::: info 文件不会离开您的电脑
PDF 在您的浏览器中读取，不会上传到任何服务器。首次检查需下载约 1 MB 的 PDF 读取组件，之后浏览器会缓存。
:::

## 结果说明

- **错误** = 必须修改 · **警告** = 需要复核 · **提示** = 供参考。
- 点击数量可按严重程度筛选；也可按规则或文件筛选，或搜索编号、页码、内容。
- **页** 为 PDF 页码；**编号** 为该问题所涉及的问题、检查点或章节。问题说明目前为英文。
- **下载 Excel 报告** 包含相同清单（汇总、问题、规则三个工作表），便于分享和跟踪整改。

## 检查内容

程序读取导出文件中的每个问题和数据点（所选选项、数字、日期、文字），并重新计算 CDP 要求细分的各项总量。

| 规则 | 严重程度 | 检查 |
|------|----------|------|
| CDP-01 | 警告 | 导出文件缺少核心问题（未作答的问题不会导出） |
| CDP-02 | 错误 | “Select from” 选项未勾选 |
| CDP-03 | 警告 | 字段留空 |
| CDP-04 | 警告 | 报告年度或基准年日期不一致 |
| CDP-05 | 错误 | 排放细分加总与报告总量不一致 |
| CDP-06 | 警告 | 同比变化（7.10.1）：各项百分比推算出的上年总量不一致 |
| CDP-07 | 错误 | 目标基准年数据加总不一致 |
| CDP-08 | 错误 | 日期晚于报告年度或导出日期（如目标设定日期晚于其“生效”年度） |
| CDP-09 | 警告 | “同上”式回答（每个回答单独评分） |
| CDP-10 | 错误 | 核查状态与核查详情不一致 |
| CDP-11 | 错误 | 百分比超出 0–100 |
| CDP-12 | 警告 | 回答语言（1.1）与正文不符 |
| CDP-13 | 警告 | 正文中年份或数字格式错误（如“204年”） |
| CDP-14 | 警告 | 范围三类别：状态与数值/解释不一致 |
| CDP-15 | 提示 | 同一段长文本粘贴在三个及以上回答中 |
| CDP-16 | 错误 | 签核（13.3）缺少职位或类别 |
| CDP-17 | 提示 | 目标基准年与 7.5 的基准年不同 |
| CDP-18 | 提示 | CDP 评分报告（不是问卷回答） |
| CDP-19 | 警告 | 占位符或未完成的文字 |
