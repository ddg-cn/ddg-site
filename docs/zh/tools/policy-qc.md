# 📚 制度文件一致性检查 <Badge type="warning" text="预览" />

把**一套公司文件**（政策、手册、程序、表单、记录）拖到下方，找出它们相互矛盾的地方：同一规定数值不同、引用的文件名称或编号不对、同一术语两种定义、保存期限不一致等。每条问题都会指出需要修改的文件和章节。

::: info 文件不会离开您的电脑
文件在您的浏览器中读取，不会上传到任何服务器。首次检查需下载约 30 KB 的读取组件（如有 PDF 另需约 1 MB），之后浏览器会缓存。

## 如何阅读结果

- **问题清单**：每条问题附整改建议。**错误** = 必须修改 · **警告** = 需复核 · **提示** = 供参考。
- **事项比对**：逐项列出比对的规定（工时、最低年龄、加班工资、假期、频次等）以及每份文件中的数值，一目了然。
- **被引用但未上传**：本套文件引用了、但您没有添加的文件。补充后再检查一次即可一并比对。
- **下载 Excel 报告**：包含问题清单、事项比对、文件清单和未上传文件清单；问题清单留有"状态"和"备注"空列，便于跟踪整改。

## 检查内容

| 规则 | 严重程度 | 检查项 |
|------|----------|--------|
| PC-01 | 错误 | 两份文件使用了同一文件编号 |
| PC-02 | 警告 | 文件抬头编号与文件名不一致 |
| PC-03 | 警告 | 引用的编号与文件名称不对应，例如 QP-HR-004《招聘管理规定》而 QP-HR-004 实为出勤规定 |
| PC-04 | 警告 | 引用的文件名称与已上传文件相近但不一致（《…管理制度》与《…管理规定》） |
| PC-05 | 警告 | 同一事项在不同文件中的数值不一致；建议值优先取政策/手册层级，否则取多数 |
| PC-06 | 警告 | 同一句话在不同文件中数字不同 |
| PC-07 | 警告 | 记录保存期限说法不一致（表单抬头与其他文件） |
| PC-08 | 警告 / 提示 | 同一术语在不同文件中定义不同 |
| PC-09 | 警告 | 适用范围或抬头中的公司名称不一致 |
| PC-10 | 提示 | 同一部门有多种叫法（质量部 / 质量管理部） |
| PC-11 | 警告 | 数值低于中国国家法定标准（童工年龄、加班上限、加班工资、产假、试用期），仅检查中文文件 |
| PC-12 | 提示 | 引用的文件编号不在已上传文件中 |
| PC-13 | 提示 | 引用的内部文件不在已上传文件中 |
| PC-14 | 提示 | 抬头字段空白或仍有占位文字 |

**比对事项：**童工年龄、未成年工年龄、每日/每周标准工时、每周最长工时、加班上限（日/月）、休息日、加班工资倍率（工作日/休息日/法定节假日）、产假、试用期、投诉举报受理及办结时限、礼品金额界限、管理评审/内审/应急演练频次、工资发放日。

::: warning 请注意
本工具为自查辅助，依据文字规律识别（以中文为主，兼顾部分英文），措辞特殊的规定可能识别不到，两个在各自语境下都正确的数值也可能被标出，请逐条判断。法定标准为中国国家层面规定，地方规定可能不同。本工具不能替代法律审核。问题说明目前为英文。
:::
