# 🏭 RBA 审核报告质检

把 **RBA 验证审核报告**（VAP 完整报告和/或执行摘要报告）拖到下方，检查数量、日期、发现和数据点是否前后一致。同时选择完整报告和摘要报告，会对两者进行比对。

::: info 文件不会离开您的电脑
PDF 在您的浏览器中读取，不会上传到任何服务器。首次检查需下载约 1 MB 的 PDF 读取组件，之后浏览器会缓存。
:::

## 结果说明

- **错误** = 必须修改 · **警告** = 需要复核 · **提示** = 供参考。
- 点击数量可按严重程度筛选；也可按规则或文件筛选，或搜索编号、页码、内容。
- **页** 为 PDF 页码；**编号** 为该问题所涉及的问题、检查点或章节。问题说明目前为英文。
- **下载 Excel 报告** 包含相同清单（汇总、问题、规则三个工作表），便于分享和跟踪整改。

## 估算得分

摘要卡片显示按发现数量估算的**得分**：200 分减去每个优先不符合项 20 分、每个严重不符合项约 6.3 分（6–7）、每个轻微不符合项约 2 分（1–3）。可用来判断工厂离 160（银）、180（金）、200（白金）还有多远；报告总分超出估算范围时，RBA-24 会提示。

## 检查内容

程序读取审核与工厂信息、符合性结果、分章节发现汇总、不符合项明细、过程总结、完整清单中的每个问题（评级、结论、数据点）以及人员数据。

| 规则 | 严重程度 | 检查 |
|------|----------|------|
| RBA-01 | 错误 | 审核或工厂信息字段缺失 |
| RBA-02 | 错误 | 审核日期顺序错误（开始 ≤ 末次会议 ≤ QC 完成）或间隔异常 |
| RBA-03 | 警告 | 审核参考编号与开始日期或国家不符 |
| RBA-04 | 错误 | 符合性结果加总不一致（符合 + 不符合 + 不适用 = 总数） |
| RBA-05 | 错误 | 分章节发现汇总与总体结果不一致 |
| RBA-06 | 错误 | 符合/轻微/严重/优先百分比与数量不符 |
| RBA-07 | 错误 | 不符合项明细与结果或完整清单中的评级不一致 |
| RBA-08 | 错误 | 执行摘要与报告不一致（发现数量、审核日期、末次会议） |
| RBA-09 | 警告 | 执行摘要清单中缺少严重/优先发现 |
| RBA-10 | 警告 | 评级与结论矛盾（不符合项缺少证据，或“符合”却描述了缺陷） |
| RBA-11 | 错误 | 法律不符合项缺少法律依据 |
| RBA-12 | 错误 | 抽样计算：“X out of Y”中 X > Y，或百分比与 X/Y 不符 |
| RBA-13 | 警告 | 所述平均值或最高值与各月数据不符 |
| RBA-14 | 警告 | 数据点中留有空值（如 “highest of hrs”、空的引用） |
| RBA-15 | 警告 | 同一句话连续重复粘贴 |
| RBA-16 | 提示 | 同一问题内的记录审阅期间不一致 |
| RBA-17 | 错误 | 人员数据加总不一致或与封面不符 |
| RBA-18 | 警告 | 评为不适用但未说明理由 |
| RBA-19 | 警告 | 常见拼写错误 |
| RBA-20 | 错误 | 执行摘要报告与完整报告不一致 |
| RBA-21 | 警告 | 占位符、“Not disclosed”或未完成的文字 |
| RBA-22 | 警告 | 总分与发现不符（超过 200，或有不符合项仍为 200） |
| RBA-23 | 提示 | 数据点或结论大部分不是英文 |
| RBA-24 | 警告 | 总分超出按发现数量估算的范围 |

::: warning 请注意
本工具是根据样本报告编写的自查辅助工具。文字类规则（如“答案为 Yes 但评论描述了缺陷”）属于经验判断，可能误报正确的答案。它 **不能** 替代各体系自身的质量审核。
:::
