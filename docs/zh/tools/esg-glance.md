# 🗺️ 气候与 ESG 评级一览 <Badge type="warning" text="预览" />

把主要的气候与供应链披露体系放在一起：谁设定了科学碳目标、谁进入 CDP A 名单、EcoVadis 奖牌如何评定、IRMA 评估了哪些矿山、RMI 列出了哪些冶炼/精炼厂。使用筛选和**分组方式**按钮，从您关心的角度查看 SBTi 和 RMI 数据，例如亚洲各行业的净零目标比例，或中小企业的 1.5°C 目标比例。本页每年更新一次。

## 数据说明

- **各体系衡量的内容不同。** SBTi 审批目标；CDP 为信息披露评分；EcoVadis 按比例对管理体系评级；IRMA 审核矿山现场；RMI 列出通过尽职调查评估的冶炼/精炼厂。同一家企业可能出现在所有名单中，也可能都不在。
- **SBTi 和 RMI 数据**按所示日期的完整公开名单（每行一家企业或工厂）统计。**CDP、EcoVadis 和 IRMA 数据**为各体系公布的总数；IRMA 所在地区为约数。
- **比例**（净零、1.5°C、承诺移除）只显示企业数不少于 20 家的分组，避免少数企业左右结果。
