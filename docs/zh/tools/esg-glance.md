# 🗺️ 气候与 ESG 评级一览

分两组对照主要体系。**气候目标、承诺与 ESG 评级**：谁设定了科学碳目标、谁进入 CDP A 名单、EcoVadis 奖牌如何评定，以及哪些企业通过 RE100 承诺 100% 使用可再生电力。**负责任矿产尽职调查**：IRMA 评估了哪些矿山、RMI 列出了哪些冶炼/精炼厂，两者都在现场层面同时涵盖社会和环境议题。使用筛选和**分组方式**按钮，从您关心的角度查看 SBTi 和 RMI 数据，例如亚洲各行业的净零目标比例，或中小企业的 1.5°C 目标比例。本页每年更新一次。

## 数据说明

- **各体系衡量的内容不同。** SBTi 审批目标；CDP 为信息披露评分；EcoVadis 按比例对管理体系评级；RE100 是一项承诺，其年度报告按 RE100 自身标准核查进展；IRMA 审核矿山现场；RMI 列出通过尽职调查评估的冶炼/精炼厂。同一家企业可能出现在所有名单中，也可能都不在。
- **SBTi、RE100 和 RMI 数据**按所示日期的完整公开名单（每行一家企业或工厂）统计；RE100 用电数据取自其年度披露报告。**CDP、EcoVadis 和 IRMA 数据**为各体系公布的总数；IRMA 所在地区为约数。
- **比例**（净零、1.5°C、承诺移除）只显示企业数不少于 20 家的分组，避免少数企业左右结果。
