# 🔎 Clarity 审核报告质检 <Badge type="warning" text="预览" />

把一份或多份 **CLARITY 现场审核报告**（社会责任、环境、健康安全、商业道德及汇总报告，或自评版本）拖到下方，在发布前进行检查。同时选择同一工厂的全部报告，还会做跨报告核对。

::: info 文件不会离开您的电脑
PDF 在您的浏览器中读取，不会上传到任何服务器。首次检查需下载约 1 MB 的 PDF 读取组件，之后浏览器会缓存。
:::

## 结果说明

- **错误** = 必须修改 · **警告** = 需要复核 · **提示** = 供参考。
- 点击数量可按严重程度筛选；也可按规则或文件筛选，或搜索编号、页码、内容。
- **页** 为 PDF 页码；**编号** 为该问题所涉及的问题、检查点或章节。问题说明目前为英文。
- **下载 Excel 报告** 包含相同清单（汇总、问题、规则三个工作表），便于分享和跟踪整改。

## 检查内容

程序读取封面、章节相关性与得分表、审核总结、不符合项行动计划联系人、“不符合项汇总”以及检查表中的每个问题（答案、评论、复核意见）。

| 规则 | 严重程度 | 检查 |
|------|----------|------|
| CL-01 | 错误 | 封面字段缺失（工厂、地址、联系人、电话、邮箱、完成人/日期、报告编号） |
| CL-02 | 错误 | 各页报告编号不一致或格式异常 |
| CL-03 | 警告 | 报告标记为草稿 |
| CL-04 | 错误 | 完成日期缺失、无法识别或晚于今天 |
| CL-05 | 错误 | 得分表：各章节不符合项之和与“Total”行不一致 |
| CL-06 | 错误 | 得分表：必要实践不符合项多于总数，或 100% 的章节仍有不符合项 |
| CL-07 | 错误 | 得分表：总分不在各章节得分范围内 |
| CL-08 | 错误 | 得分表不符合项数与“不符合项汇总”行数不一致 |
| CL-09 | 错误 | 审核总结中的不符合项数量（或“无不符合项”）与得分表不一致 |
| CL-10 | 错误 | 不符合项行动计划联系人：有不符合项却填 NA/空白（或无不符合项却填写） |
| CL-11 | 错误 | 不符合项汇总行缺少状态或目标完成日期 |
| CL-12 | 警告 | 目标完成日期早于审核日期，或晚于审核日期 12 个月以上 |
| CL-13 | 警告 | 状态为 Open 但评论称整改已接受/关闭（或 Closed 却无跟进证据） |
| CL-14 | 警告 | 汇总中列为不符合项，但检查表答案为“Yes”（或检查表中没有该检查点） |
| CL-15 | 错误 | 检查表问题未作答 |
| CL-16 | 错误 | “No”“Partially”或“NA”答案缺少评论 |
| CL-17 | 警告 | “Yes”答案没有评论（未记录证据） |
| CL-18 | 警告 | 答案为“Yes”但评论描述了缺陷（答案可能有误） |
| CL-19 | 警告 | 评论过短或过于笼统，不足以作为证据 |
| CL-20 | 警告 | 评论不是英文 |
| CL-21 | 提示 | 同一评论粘贴在三个及以上问题 |
| CL-22 | 警告 | 评论引用的日期晚于审核日期 |
| CL-23 | 错误 | 章节标记“Not Relevant”但未说明理由 |
| CL-24 | 警告 | 审核总结缺失、过短或仍为模板文字 |
| CL-25 | 警告 | 占位符或未完成的文字 |
| CL-26 | 错误 | 汇总报告：缺少员工人数或优势/不足 |
| CL-27 | 警告 | 同一工厂的多份报告不一致（工厂名称、审核员，或审核日期相差超过 60 天） |
