# 🌐 amfori BSCI 审核报告质检 <Badge type="warning" text="预览" />

把 **amfori BSCI 审核报告**（平台导出、Monitoring result 或 Monitoring summary report）拖到下方，检查评级、发现、工人数据、工资工时和日期是否前后一致。同一工厂的多份报告会相互比对。

::: info 文件不会离开您的电脑
PDF 在您的浏览器中读取，不会上传到任何服务器。首次检查需下载约 1 MB 的 PDF 读取组件，之后浏览器会缓存。
:::

## 结果说明

- **错误** = 必须修改 · **警告** = 需要复核 · **提示** = 供参考。
- 点击数量可按严重程度筛选；也可按规则或文件筛选，或搜索编号、页码、内容。
- **页** 为 PDF 页码；**编号** 为该问题所涉及的条款、问题或发现编号。问题说明目前为英文。
- **下载 Excel 报告** 包含相同清单（汇总、问题、规则三个工作表），便于分享和跟踪整改。

## 检查内容

| 规则 | 严重程度 | 检查 |
|------|----------|------|
| BSCI-01 | 错误 | 关键审核或工厂字段缺失（编号、工厂、地址、日期、审核机构、审核员、评级） |
| BSCI-02 | 错误 | 审核日期顺序错误、在未来，或报告内前后不一致 |
| BSCI-03 | 警告 | 有效期/跟进日期与评级不符（A/B：2 年；C/D/E：12 个月，跟进审核在全面审核后 2–12 个月内） |
| BSCI-04 | 提示 | 报告在最后审核日后超过 15 个日历日才提交 |
| BSCI-05 | 警告 | 总体评级与各绩效领域评级的推导结果不符 |
| BSCI-06 | 错误 | 报告各部分的评级不一致（评级表、绩效领域标题、汇总表） |
| BSCI-07 | 错误 | 绩效领域评为 B–E，但没有列出任何未关闭的发现 |
| BSCI-08 | 警告 | 摘要中列出的有发现的领域/问题与发现部分不一致 |
| BSCI-09 | 警告 | 发现引用的问题编号与标题不符或属于其他绩效领域 |
| BSCI-10 | 警告 | 发现缺少具体情况描述 |
| BSCI-11 | 错误 | 发现声称违反法律，但未引用任何法律、条例或条款 |
| BSCI-12 | 错误 | 工人数据加总不一致，或指标与描述不符 |
| BSCI-13 | 错误 | 抽样计算：“X out of Y”中 X > Y，或百分比与 X/Y 不符 |
| BSCI-14 | 错误 | 最低工资低于法定最低工资，但没有相应的工资发现 |
| BSCI-15 | 警告 | 描述了每周超过 60 小时，但“体面工时”没有发现 |
| BSCI-16 | 警告 | 领域被描述为符合，但文字描述了缺陷 |
| BSCI-17 | 警告 | 占位符、空白或未完成的文字 |
| BSCI-18 | 警告 | 同一句话连续重复粘贴 |
| BSCI-19 | 警告 | 常见拼写错误 |
| BSCI-20 | 警告 | 报告中提到零容忍问题 |
| BSCI-21 | 提示 | 关键（CRUCIAL）问题存在发现 |
| BSCI-22 | 警告 | 审核描述（天数、日期、人天）与报告抬头不一致 |
| BSCI-23 | 错误 | 同一工厂在两份报告中的工厂信息或工人数量不一致 |
| BSCI-24 | 提示 | 同一工厂不同审核之间的评级变化 |

::: warning 请注意
适用于 13 个绩效领域的报告（2018 平台导出、2021 Monitoring result、2023 Monitoring summary）。2021 和 2023 版的总体评级是彩色色块而非文字，因此按 13 个领域评级推导并标为“推导”。总体评级规则（BSCI-05）依据公开的方法概述；amfori 未公开计算方法，故设为警告而非错误。新版 6 个绩效领域方法的报告只做全文检查。
:::
