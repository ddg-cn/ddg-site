# 🧰 工具

所有检查都在您的浏览器中运行：文件在本机读取，不会上传。每个工具都在页面上列出检查结果，并可导出为 Excel。

## 报告质检

| 工具 | 检查内容 | 输入 | English |
|------|--------|-------|------|
| [🧾 **报告质检**](/zh/tools/report-qc.html) <Badge type="warning" text="预览" /> | **从这里开始。** 可同时拖入 Clarity、RBA、SMETA、amfori BSCI、EcoVadis 和 CDP 的 PDF，自动识别每个文件的类型并做下列相应检查。下列各页说明每类报告的规则 | PDF（可多个、可混合） | [English](/en/report-qc.html) |
| [🔎 Clarity 审核报告质检](/zh/tools/clarity-qc.html) | Bureau Veritas CLARITY 现场审核及自评报告：得分与不符合项数量、不符合项汇总、答案与备注、同一工厂各报告之间的核对 | PDF（一个或多个） | [English](/en/clarity-qc.html) |
| [🌍 CDP 问卷回答质检](/zh/tools/cdp-qc.html) | CDP 问卷回答导出文件：缺失的核心问题、未勾选的选项、空白字段、排放分项与合计、目标与基准年日期 | PDF | [English](/en/cdp-qc.html) |
| [🏭 RBA 审核报告质检](/zh/tools/rba-qc.html) | RBA VAP 验证审核报告：结果、章节汇总与不符合项清单是否一致，估算得分，执行摘要，日期，数据点计算，法规引用 | PDF（完整版和/或摘要版） | [English](/en/rba-qc.html) |
| [🧭 SMETA 审核报告质检](/zh/tools/smeta-qc.html) <Badge type="warning" text="预览" /> | SMETA 7 审核报告及 CAPR：汇总与发现详情、不完整的不符合项、工人与访谈人数、工资工时超标却未开不符合项、CAPR 时间线、报告与 CAPR 是否一致 | PDF（报告和/或 CAPR） | [English](/en/smeta-qc.html) |
| [🌐 amfori BSCI 审核报告质检](/zh/tools/bsci-qc.html) <Badge type="warning" text="预览" /> | amfori BSCI 报告：总评级与各绩效领域评级、有评级却无发现、有效期、工人人数、工资工时、法规引用、同一工厂各报告比较 | PDF（一个或多个） | [English](/en/bsci-qc.html) |
| [🌱 EcoVadis 问卷质检](/zh/tools/ecovadis-qc.html) | EcoVadis 问卷导出文件：未完成的问题、标注的页码、文件名称、KPI 数值与目标年份 | PDF（Survey Full） | [English](/en/ecovadis-qc.html) |
| [📚 制度文件一致性检查](/zh/tools/policy-qc.html) <Badge type="warning" text="预览" /> | 一套政策、手册、程序和表单：同一规定数字不同、引用的文件名称或编号错误、术语有两种定义、保存期限、中国法定最低要求 | .docx / PDF / .txt（多个） | [English](/en/policy-qc.html) |
| [🌡️ 碳足迹表格检查](/zh/tools/carbon-qc.html) <Badge type="warning" text="预览" /> | 产品碳足迹表格（欧盟电池碳足迹报告模板、客户 PCF 模板、LCI 数据表），按您选择的标准检查（欧盟电池、PEF、ISO 14067、GHG Protocol、PACT、Catena-X、TfS）：数据集与部件是否对应、建议的 TeR / GeR / TiR / P 及理由、DQR 计算、排放因子与公开范围比较、数量 × 排放因子 | .xlsx / .xlsm（多个） | [English](/en/carbon-qc.html) |
| [🧪 SLCP 核查工具在线质检](/zh/tools/slcp-qc.html) <Badge type="info" text="未列出" /> | 已填写的离线 SLCP 核查工具 1.7.x，包括 SLCP 平台的自动数据质量检查 | .xlsm | [English](/en/slcp-qc.html) |
