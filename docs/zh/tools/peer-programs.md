# 主要社会责任审核项目一览

各主要社会责任审核项目每年报告的审核 / 评估数量，以及会员、覆盖国家、工厂和工人等覆盖范围。所有数字均来自项目自己的年报、公开申报文件或官网，每季度根据新发布的报告更新。

## 如何解读

- **各项目的统计口径不同。** SLCP 统计已核查的评估，RBA 统计 VAP（验证评估计划）审核，SA8000 统计获证工厂，FLA 统计其对会员部分工厂的抽样评估，Higg FEM 统计经核查的环境评估（它是与 SLCP 对应的环境模块，并非社会责任审核）。其余项目统计审核次数。
- **"会员"不能跨项目比较。** SLCP 指签署方，amfori 和 RBA 指会员企业，SMETA 指 Sedex 全部会员（含买家和供应商），Better Work 指品牌和零售商合作伙伴，FLA 指参与企业，Fair Wear 指会员品牌。
- **Better Work 和 Fair Wear 不公布全球年度总数。** 其数字取自官网在所示日期显示的计数（往年取自网站存档），属于时点数据而非年度总数。Fair Wear 的工厂数为会员品牌公开披露的工厂。
- **只显示项目公开报告的数字。** 未报告的年份留空，不做估算。
- 鼠标悬停图表上的点可查看数值；"来源"一列链接到所用的最新报告。
