# 负责任签约

**合作开始时签下的合同，决定了日后职工的境遇**

*简明指南，2026年11月第1版。适用于买方（品牌、进口商、贸易公司）和供应商工厂，特别是中国的中小制造企业。本文属于系列指南之一：[业务关系生命周期](/zh/ddg#_0-8-各指南的位置-业务关系的生命周期)的第二阶段。*

::: tip 一分钟读懂
1. **大多数供货合同是单向的。** 供应商保证完全遵守买方的行为准则；买方对价格、交期和变更却什么都不承诺。现在已经有示范条款来解决这个问题。
2. **把买方的义务写进去。** 价格要覆盖法定工资，交期要现实，订单变更要书面确认，取消的订单要为已做的工作付钱，不得事后追加折扣。
3. **付款：60天以内，下单前约定。** 中国法律规定大型企业向中小企业付款的默认期限为60天，并禁止"背靠背"付款。
4. **所有罚款在签约时一次列明**，以实际损失为上限；买方逾期付款同样构成违约。
5. **认可同等的审核结果**，不要重复审核，并写明由谁付费。
6. **现在就规划好退出。** 一条对双方都有约束力的负责任退出条款，签的时候不花钱，缺了它代价却很大。
:::

---

## 1. 合同为什么重要

买方的行为准则通常作为附件放进合同，列出供应商必须保证做到的事项。起草最常用示范条款的美国律师协会（ABA）工作组认为，这种"单方保证"的做法"既不现实，也没有效果"：它把尽职调查变成了打勾走过场，对买方自身在问题中扮演的角色只字不提。

而买方的角色是实实在在的。低于成本的价格、过短的交期、临时变更和取消订单，会把工厂推向超时加班、未经授权的分包和拖欠工资：

| 证据 | 发现 |
|---|---|
| 国际劳工组织（ILO）与道德贸易倡议（ETI）全球供应商调查（87个国家的1,454家供应商） | 只有 **17%** 的供应商表示交期足够 |
| 《被抛弃？》（孟加拉国316家供应商，2020年3月） | 订单被取消时，**72.1%** 的买方拒绝支付已采购的原材料费用，**91.3%** 拒绝支付生产成本 |
| 阿伯丁大学与Transform Trade（约1,000家孟加拉国工厂，2023年） | **20%** 的工厂实收货款低于合同价；**25%** 在交货三个月后才收到货款 |
| Better Buying（"更好采购"）采购实践指数2025（1,360家供应商） | 只有 **43.6%** 的付款期在60天以内；中国供应商更常反映付款期在 **91天以上** |

把双方义务都写清楚的合同，是预防这些问题成本最低的地方。合作如何结束，也在合同里就定下了：[负责任退出指南](/zh/exit-guide)说明了，合同对预告期、在制品付款和模具只字未提时，退出会难上多少。

## 2. 从哪些示范条款入手

不需要从零起草。三套示范条款已经涵盖了一份公平供货合同所需的大部分内容。

| 示范文本 | 年份 | 面向 | 新增内容 |
|---|---|---|---|
| **ABA《示范合同条款2.0》**（ABA MCCs 2.0），附**Schedule Q**（附表Q，即面向买方的《负责任采购行为准则》） | 2021 | 买方 | 以双方各自开展尽职调查取代单方保证（§1.1）；买方在价格、订单变更和协助方面的义务（§1.3）；终止合同前给予纠正机会并制定整改计划（§2.3–2.4）；买方违约促成损害的，相应减少供应商的赔偿责任（§6.5(b)） |
| **负责任合同项目（Responsible Contracting Project）《供应商示范合同条款1.0》**（SMCs，下称SMC） | 2023 | 供应商（与一批制造商共同起草） | 对买方义务规定得最具体：订单预测（3.2）、预留产能须付费（3.3）、样品数量设上限（3.4）、取消订单按订单变更处理（3.9）、罚款须在签约时列明并以实际损失为上限（3.12）、认可同等的第三方审核（3.13）、任何一方退出均须负责任（9） |
| **《欧洲示范条款》**（EMCs） | 2024年零草案；1.0版预计2026年底发布 | 双方，配合欧盟尽职调查法律 | 共同责任、信息共享、申诉、补救、负责任采购和退出。最终文本请查阅responsiblecontracting.org。 |

另有两套适用于特定条款：
- **国际商会（ICC）《不可抗力和艰难情形条款》（2020年）**，其中包括适合中小企业的简短版本；障碍持续超过120天的，任何一方都可以解除合同。
- **The Chancery Lane Project**（钱瑟里巷项目）的气候条款，用于碳排放和环境条款。要配合成本分担条款使用；把气候义务推给既没有数据也没有资金的小供应商，同样是单向合同的老问题。

根据经修订的CSDDD（欧盟《企业可持续发展尽职调查指令》）第18条，欧盟委员会须在**2027年7月26日**前发布关于自愿性示范条款的指引。

**谁在用。** C&A已按SMC改写了供货条款，并按ACT（行动、合作、转型倡议）的劳动力成本核算规程把人工成本单列、专款专用。Ganni、HAKRO和B Corp（共益企业）标准也参考了这些条款。Zeeman公布了双向适用的行为准则，并在发货后14天内向供应商付款。

## 3. 要写进去的商业条款

合同最容易出问题的六个方面，以及负责任的写法和出处。

| 条款 | 负责任的写法 | 出处 |
|---|---|---|
| **价格** | 覆盖全部生产成本，包括法定工资、福利和职业健康安全。尽可能单列人工成本。最低工资、原材料价格或汇率大幅变动时重新议价。 | Schedule Q 3.3、4.6；SMC 3.6、3.8；CFRPP（《负责任采购实践共同框架》）原则5；ACT |
| **付款** | 下单前约定；60天以内；不得事后更改；对小供应商支付定金或缩短付款期 | Better Buying；CFRPP原则4；Schedule Q 4.10 |
| **预测与产能** | 尽早共享并说明依据；只有双方约定的部分才有约束力；预留产能要付费 | SMC 3.2–3.3；CFRPP原则3 |
| **订单变更** | 书面确认；相应调整价格和交期；会导致超时加班的变更，供应商可以拒绝，买方不得报复 | Schedule Q 4.1–4.4；SMC 3.9；ABA §1.3(d)–(e) |
| **取消订单** | 按订单变更处理：成品、在制品和已采购的物料都要付钱 | SMC 3.9；新冠疫情的教训 |
| **罚款与扣款** | 全部在签约时列明；事后不得增加；以实际损失为上限；须提供证据；买方逾期付款同样构成违约 | SMC 3.12；CFRPP原则4 |

**新冠疫情的教训。** 2020年3月，许多买方以不可抗力为由取消了已完成和正在生产的订单。Primark先是停止下单，后来承诺为在产货物支付3.7亿英镑；H&M、adidas、Inditex和PVH也承诺付款。另一些买方则没有。合同里写明了在制品付款的，供应商可以据此索赔；全凭买方自觉的，供应商只能等社会运动替他们出头。

## 4. 审核、数据与补救

- **认可同等的审核。** SMC 3.13允许供应商提供近期的同等第三方审核或共享评估结果，除非达不到最低标准，否则买方应予认可。重复审核耗费工厂的时间和金钱，却没有任何增益。
- **写明谁付费。** 根据经修订的CSDDD第10条第5款，企业要求中小企业合作伙伴作出合同保证的，条款必须"公平、合理、无歧视"，独立第三方核查的费用由企业承担。"综合简化"一揽子法案（Omnibus I）还限制了信息索取：对员工不足5,000人的合作伙伴，只能索取无法通过其他途径合理获得的信息（新增第8条第2a款）。
- **依法处理职工数据。** 审核会收集姓名、身份证号、工资和访谈记录。把这些数据传到境外，须符合《个人信息保护法》（第38–39条）规定的合法途径，多数情况下还要取得单独同意。合同里要写明收集哪些数据、如何最小化或匿名化处理、存放在哪里、提供给谁。
- **先整改，再终止。** 纠正机会和整改计划（ABA §2.3–2.4）能保护职工免受突然退出的伤害。只有零容忍问题才立即终止合同。
- **写明申诉渠道。** 说明供应商的职工可以通过什么途径反映问题，包括因买方做法引起的问题。参见[申诉渠道](/zh/grievance-guide)。

## 5. 给工厂：签约时要知道的中国法律

| 事项 | 规则 | 实务要点 |
|---|---|---|
| **格式条款** | 提供格式条款的一方应当提示对方注意免除或减轻其责任的条款；未提示的，对方可以主张该条款不成为合同的内容。不合理地免除提供方责任、限制对方主要权利的格式条款无效；对格式条款有两种以上解释的，作不利于提供方的解释。*（《民法典》第496–498条）* | 这些规定只有在**适用中国法律时**才能保护你。依赖它们之前，先看合同的法律适用条款。 |
| **违约金** | 约定的违约金过分高于造成的损失的，法院或仲裁机构可以适当减少 *（第585条）* | 签约时仍要把违约金谈下来；是否减少由法院或仲裁机构裁量。 |
| **不可抗力** | 应当及时通知，并在合理期限内提供证明；迟延履行后发生不可抗力的，不免除责任 *（第590条）* | 事情发生当天就留好记录。 |
| **情势变更** | 发生无法预见的重大变化，继续履行对一方明显不公平的，可以重新协商，协商不成的，可请求法院或仲裁机构变更或解除合同 *（第533条）* | 不能代替价格调整条款。 |
| **大型企业付款** | 大型企业从中小企业采购货物，应当自货物交付之日起60日内付款，另有合理约定的除外；不得约定"背靠背"付款；不得强制要求以商业汇票结算 *（《保障中小企业款项支付条例》（国务院令第802号）第9条、第11条；2025年6月1日起施行）* | 签约时告知买方你是中小企业（第3条）。这条规定显然适用于买方在中国的采购主体；对在境外签约的买方是否适用，尚不确定。 |
| **争议解决** | 修订后的《仲裁法》于2026年3月1日起施行 | 约定解决途径：先协商，再调解，然后仲裁或诉讼。 |

**制裁条款。** 很多买方合同规定，供应商被列入制裁名单的，买方可以停止付款。对中国一方援引这类条款，买方可能面临依据《反外国制裁法》（第12条）和2026年《反外国不当域外管辖条例》（国务院令第835号）提起的诉讼。2024年，一家被列入美国制裁名单的中国工程企业起诉了停止付款的外国客户；南京海事法院扣押了该客户的船舶，案件最终和解。更稳妥的条款是：在制裁允许的范围内，**通知、协商，并为已交付的货物付款**。参见[负责任退出指南第9章](/zh/exit-guide#_9-情形五-制裁、进口禁令和法律冲突导致的被迫退出)。

## 6. 法律对合同有哪些要求

比人们以为的要少。我们查阅的法律中，没有一部规定了具体条款。

| 法律 | 与合同有关的义务 |
|---|---|
| **欧盟CSDDD**（经修订，2029年7月起适用） | 要求直接合作伙伴作出合同保证，并加以核查（第10条第2款(b)项、第5款）；调整企业自身的采购做法（第10条第2款(d)项）；支持中小企业合作伙伴（第10条第2款(e)项）。仅有合同保证不足以证明合规，也不得把企业自身的义务转嫁给供应商。 |
| **德国《供应链尽职调查法》（LkSG）**第6条第4款 | 在选择供应商时考虑人权和环境要求；取得合同保证，并沿供应链逐级传递；开展培训；约定审核等合同监督机制 |
| **中国** | 《民法典》关于格式条款和违约金的规定；国务院令第802号关于向中小企业付款的规定 |

**标准比法律要求更高。** SA8000:2026要求获证组织为业务伙伴制定"相互期望"政策，其中包括对终止业务关系的明确预期（M4.2）。在与业务伙伴往来时，其商业条款和做法不得削弱对方达到这些期望的能力；须按自身对问题的影响程度向对方提供支持，并尽量减轻对方的行政负担；只有在对方获得支持后仍反复未能解决、且终止关系的风险不大于原有风险时，才可因风险终止业务关系（M7.4）。

法律的最低要求只是一条行为准则条款。负责任的做法，是上文所说的双向合同。
