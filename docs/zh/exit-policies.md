# 负责任退出政策范本

三份简短的政策供参考修改：一份适用于**买方**（品牌、零售商、进口商），一份适用于**工厂**，一份适用于代表买方下单的**代理或贸易公司**。三份政策结构相同，便于合作双方了解对方作出的承诺。内容取材于[《负责任退出指南》](./exit-guide)以及已公开的政策和指引：ACT（2022年）、C&A（2025年）、Fair Wear、FLA（2023年）、ETI与Shift（2026年）、美国律师协会（ABA）和负责任合同项目（Responsible Contracting Project）的示范条款，以及中国法律。

请替换[方括号]中的内容，删除不适用的部分，并请律师按所在地法律审核定稿。[按角色划分的检查清单](./exit-checklist)可将这些承诺转化为具体步骤。

## 1. 买方政策

**[公司名称]负责任退出政策**
*由[审批机构]于[日期]批准。负责部门：[职能部门，例如采购负责人]。每[两]年复审一次。*

### 1.1 目的
我们有时需要减少或停止向某一供应商下单。届时，我们将以不把成本转嫁给供应商职工的方式退出。本政策规定具体做法。

### 1.2 适用范围
本政策适用于：
- 对供应商、其分包商或我们的代理为我们的订单所使用的工厂，作出终止、暂停或大幅减少订单（与前12个月或约定预测相比减少超过[30]%）的每一项决定；
- 代理或供应商将我们的订单转移到其他工厂；
- 因制裁、进口禁令或其他法律要求而必须进行的退出。

### 1.3 原则
1. **先沟通改进，后退出。** 如退出原因是劳工、人权或环境问题，我们首先运用自身影响力推动整改。只有在整改失败或无法整改，或法律要求时，才终止合作关系。
2. **通知期与依赖程度相当。** 我们占供应商产量的比例越大，通知期越长，减单越平缓。
3. **先付清应付款项。** 我们支付按我们指示生产的货物和采购的物料的款项，不借退出之机提出新的索赔、折扣或罚款。
4. **告知并保护职工。** 我们要求供应商告知其职工代表并与其协商，并核实工资和经济补偿已足额支付。
5. **保留证据，保持联系。** 我们保存每次退出的记录，在最后一批订单之后继续开放申诉渠道。

### 1.4 承诺
| 我们占供应商产量的比例（近12个月） | 最短通知期和减单期 |
|---|---|
| 低于10% | 一个订单周期或一季（约3个月） |
| 10%–30% | 6个月，并按月提供书面订单量预测 |
| 超过30%，或我们是唯一或主要买方 | 6–12个月，分阶段减单，承诺最后一批订单，并核实供应商有能力支付经济补偿 |
| 因严重侵权或法律要求而退出 | 按原因或法律要求的最短期限，并采取一切剩余措施减少损害 |

我们还将：
- 考虑供应商的生产旺季、春节以及其他买方同时退出的情况；
- 如供应商需要资金支付经济补偿，主动提出提前支付尾款；
- 不取消已投产的订单，除非支付已发生的成本。

### 1.5 程序
1. **决策。** 采购经理记录退出原因和证据，并进行影响评估（依赖程度、受影响职工、应付款项、社会保险欠缴、时间安排、替代方案）。对我们占比超过[30]%的供应商，或因人权问题退出的，由[负责任采购委员会]审批。
2. **通知。** 我们发出书面通知，说明原因、时间表和按月订单量预测，并要求供应商将通知告知其工会或职工代表。
3. **收尾。** 我们与供应商书面约定未完成订单、在制品、物料、包装、模具、技术文件和数据的处理方式。
4. **付款与核实。** 我们按时付款。如退出导致裁员，我们要求供应商提供裁员方案、经济补偿计算表和支付凭证。
5. **退出后。** 我们的申诉渠道在至少六个月内继续向供应商职工开放。如获悉职工未获支付，我们将通过调解、出资或补救等方式采取行动。
6. **被迫退出。** 如因制裁或进口禁令被迫退出，由法务部门确定退出日期。我们在法律允许的范围内支付已生产货物的款项、发出通知并支持职工，必要时申请许可。

### 1.6 信息公开
如我们公开供应商名单，在供应商退出时更新名单并注明日期。我们在[年度可持续发展报告或尽职调查报告]中披露退出次数及处理情况。

### 1.7 职责
| 责任人 | 职责 |
|---|---|
| [采购负责人] | 在每次退出中执行本政策；培训采购人员 |
| [负责任采购/企业社会责任部门] | 影响评估、与职工相关的跟进、申诉渠道 |
| [法务部门] | 合同、制裁和进口禁令相关决定、反制措施风险、数据 |
| [财务部门] | 按时付款；退出时不新增扣款 |

### 1.8 记录
每次退出，我们保存以下资料[五]年：决策及原因、影响评估、通知、订单量预测、收尾协议、付款记录，以及与职工相关的证据（通知、协商、经济补偿）。

## 2. 工厂政策

**[工厂名称]终止客户合作、关闭与搬迁政策**
*由[股东/董事会]于[日期]批准。负责人：[总经理]。每[两]年复审一次。*

### 2.1 目的
职工不应为他们没有参与的决定买单。本政策规定我们如何终止与客户的合作，以及在关闭、搬迁或裁减人员时的做法，符合中国法律和客户的行为准则。

### 2.2 适用范围
- 终止或不再续签客户合作。
- 因经济原因裁减人员。
- 全部或部分关闭工厂。
- 在本市、跨省或向境外搬迁。

### 2.3 原则
1. **按法定顺序办理。** 协商、支付、转移、清算、注销，不跳过任何步骤。
2. **工资和经济补偿优先**，先于其他债权人，先于股东，先于在其他地方的新投资。
3. **先安置，后解除。** 我们首先寻找替代方案：调到其他产线、减少加班、培训、调岗。
4. **尽早书面告知。** 告知职工、工会、客户、供应商、房东和有关部门。
5. **清理好场地再离开。** 离开前处理好废物、土壤和各类许可。

### 2.4 承诺
- 我们保持不低于经济补偿总额[三]个月的**经济补偿准备金**，每[六]个月复核一次。
- 我们**按全额工资缴纳社会保险和住房公积金**。
- 停止供货前，我们至少提前[合同约定的通知期，且不少于30天]书面通知客户，并尽可能完成合法的未完成订单。
- 没有法律依据，我们不扣留客户的模具或货物作为担保。
- 我们不要求职工"自愿"辞职以规避经济补偿，也不在任何和解协议中加入放弃法定权利的条款。
- 搬迁时，我们以书面形式提出调动安排，写明交通、住宿和工资条件，并向不愿随迁的职工支付经济补偿。向境外搬迁视为中国境内用人单位关闭。
- 在旧厂职工的欠款付清之前，我们不在国内或境外另起炉灶经营同类业务。

### 2.5 程序
1. **决策。** 股东或董事会在听取工会和职工意见后作出书面决议并说明理由（《公司法》第17条）。我们进行影响评估，并为每位受影响职工计算经济补偿。
2. **准备。** 我们核查并补缴社会保险和住房公积金欠缴；列出需要退还、完成或移交的补贴、税收优惠、土地条件和资助项目；委托开展环境收尾工作（危险废物、按要求开展的土壤调查、许可、费用）。
3. **说明与协商。** 涉及20人以上，或占职工总数10%以上的，我们提前30日向工会或全体职工说明情况，听取意见，并向劳动行政部门报告（《劳动合同法》第41条）。受保护职工（第42条）逐一处理。
4. **通知。** 向客户、供应商和房东发出书面通知，写明日期和联系人。
5. **支付。** 按时通过银行转账支付截至最后一天的工资、停工停产期间工资、经济补偿（第46–47条）、未休年休假工资及任何欠款。
6. **转移。** 在15日内出具解除劳动合同证明，办理档案和社会保险关系转移（第50条）。
7. **关闭。** 按法定顺序清算（《公司法》第236条）。工资清偿完毕后方可申请注销（《保障农民工工资支付条例》第22条）。

### 2.6 职责
| 责任人 | 职责 |
|---|---|
| [股东/总经理] | 决策、提取准备金、整体合规 |
| [人事部门] | 协商、向劳动行政部门报告、经济补偿、证明和转移手续 |
| [财务部门] | 准备金、付款记录、清算顺序 |
| [环境健康安全部门] | 环境收尾 |
| [销售部门] | 客户通知和商务收尾 |

### 2.7 记录与联系人
我们保存决议、协商会议纪要、劳动行政部门回执、经济补偿计算表、付款记录和环境相关文件，保存期限至少为[关闭后两年，法律要求更长的从其规定]。退出后[六]个月内，由指定联系人答复职工和客户的问题。

## 3. 代理或贸易公司政策

**[公司名称]下单业务负责任退出政策**
*由[董事]于[日期]批准。每[两]年复审一次。*

### 3.1 目的
我们代表客户向工厂下单。我们把订单从某家工厂转走，对其职工的影响与品牌退出相同。本政策确保我们和客户以负责任的方式处理。

### 3.2 适用范围
我们或客户作出的、终止、暂停或大幅减少在我们所用工厂的订单的每一项决定，包括将订单转移到其他工厂、我们的其他供应商或其他国家。

### 3.3 承诺
1. **告知客户。** 将品牌的订单从某家工厂转走之前，我们先告知该品牌，因为根据许多品牌的政策（例如ACT），这种转单视为品牌的退出。
2. **执行买方通知期。** 我们按合并订单占工厂产量的比例给予工厂通知期（见第1.4节表格），客户政策要求更长的从其规定。
3. **足额、按时转付款项。** 退出时，我们不扣留应付工厂的款项来抵偿我们自己的索赔。
4. **告知工厂需要了解的信息。** 以书面形式提供原因、时间表和订单量预测；工厂位于中国的，使用中文。
5. **收集证据。** 如随后发生裁员，我们收集工厂的裁员方案和支付凭证，并转交客户。
6. **保留联系人。** 最后一批订单之后六个月内，我们为工厂及其职工指定联系人。

### 3.4 客户退出时
客户停止通过我们下单时，我们一经得知即告知相关工厂，告知客户的时间表，并要求客户执行其退出政策。我们不向工厂隐瞒客户的退出。

### 3.5 记录
每次退出，我们保存决策、通知、订单量预测、付款记录和与职工相关的证据[五]年，并应客户要求提供。
