# 🧰 Tools

Every checker runs in your browser: the file is read on your computer and is not uploaded. Each one lists the findings on the page and exports them to Excel.

## Report quality checkers

| Tool | Checks | Input | 中文 |
|------|--------|-------|------|
| [🧾 **Report QC**](/en/report-qc.html) <Badge type="warning" text="preview" /> | **Start here.** Drop any mix of Clarity, RBA, SMETA, amfori BSCI, EcoVadis and CDP PDFs; the type of each file is detected and it gets the checks below. The pages below explain the rules of each report type | PDF (several, mixed) | [中文](/zh/tools/report-qc.html) |
| [🔎 Clarity Audit Report QC](/en/clarity-qc.html) | Bureau Veritas CLARITY field audit and self-assessment reports: scores vs NC counts, NC overview, answers vs comments, cross-checks between the reports of one site | PDF (one or more) | [中文](/zh/tools/clarity-qc.html) |
| [🌍 CDP Response QC](/en/cdp-qc.html) | CDP questionnaire response export: missing core questions, unticked options, blank fields, emissions breakdowns vs totals, target and base-year dates | PDF | [中文](/zh/tools/cdp-qc.html) |
| [🏭 RBA Audit Report QC](/en/rba-qc.html) | RBA VAP validated audit reports: results vs section summary vs NC list, estimated score, executive summary, dates, data-point arithmetic, legal references | PDF (full and/or summary) | [中文](/zh/tools/rba-qc.html) |
| [🧭 SMETA Audit Report QC](/en/smeta-qc.html) <Badge type="warning" text="preview" /> | SMETA 7 audit reports and CAPRs: summary vs finding details, incomplete NCs, worker and interview numbers, wages and hours breaches without an NC, CAPR timelines, report vs CAPR | PDF (report and/or CAPR) | [中文](/zh/tools/smeta-qc.html) |
| [🌐 amfori BSCI Audit Report QC](/en/bsci-qc.html) <Badge type="warning" text="preview" /> | amfori BSCI reports: overall vs Performance Area ratings, rated areas without findings, validity dates, worker numbers, wages and hours, legal references, reports of one site compared | PDF (one or more) | [中文](/zh/tools/bsci-qc.html) |
| [🌱 EcoVadis Questionnaire QC](/en/ecovadis-qc.html) | EcoVadis questionnaire export: incomplete questions, indicated pages, document names, KPI values and target years | PDF (Survey Full) | [中文](/zh/tools/ecovadis-qc.html) |
| [📚 Policy Consistency Check](/en/policy-qc.html) <Badge type="warning" text="preview" /> | A set of policies, manuals, procedures and forms: the same rule with different numbers, wrong document names or codes in references, terms defined two ways, retention periods, PRC statutory minimums | .docx / PDF / .txt (several) | [中文](/zh/tools/policy-qc.html) |
| [🌡️ Carbon Footprint Form Check](/en/carbon-qc.html) <Badge type="warning" text="preview" /> | Product carbon footprint forms (EU battery CFR template, customer PCF templates, LCI data sheets), checked against a standard you pick (EU battery, PEF, ISO 14067, GHG Protocol, PACT, Catena-X, TfS): dataset vs component, suggested TeR / GeR / TiR / P with reasons, DQR arithmetic, factors vs public ranges, quantity × EF | .xlsx / .xlsm (several) | [中文](/zh/tools/carbon-qc.html) |
| [🧪 SLCP Verifier Tool QC](/en/slcp-qc.html) <Badge type="info" text="unlisted" /> | Filled offline SLCP Verifier Tool 1.7.x, including the SLCP platform's automated data quality checks | .xlsm | [中文](/zh/tools/slcp-qc.html) |
